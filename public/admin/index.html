  • 운영 전: 대시보드 접속과 인증 상태를 확인합니다.
  • 운영 중: 교환 대기와 인증 대기 건을 주기적으로 확인합니다.
  • 운영 중: 최근 포인트 로그와 반응 승인 기록을 대조합니다.
  • 운영 후: /운영내보내기로 백업 파일을 확보합니다.
