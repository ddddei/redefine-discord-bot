  • 오늘 백업 체크: 운영 시작 전 또는 종료 전 전체 JSON을 확보합니다.
  • 추천: /운영내보내기 종류:전체 형식:JSON
  • /운영내보내기 종류:포인트 형식:CSV
  • /운영내보내기 종류:교환 형식:JSON
  • /운영내보내기 종류:인증 형식:JSON
  • 마지막 확인: 예시 데이터 제외 건수, pending 항목, 최근 포인트 로그

운영 체크리스트

  • 운영 전: 대시보드 접속과 인증 상태를 확인합니다.
  • 운영 중: 교환 대기와 인증 대기 건을 주기적으로 확인합니다.
  • 운영 중: 최근 포인트 로그와 반응 승인 기록을 대조합니다.
  • 운영 후: /운영내보내기로 백업 파일을 확보합니다.
