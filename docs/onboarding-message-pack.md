# 프로젝트 리디파인 72시간 온보딩 운영 메시지 패키지

선발된 참여자가 디스코드에 입장한 뒤 72시간 동안 안정적으로 적응할 수 있도록, 운영진이 복사해 사용할 수 있는 공지문과 안내 메시지를 정리한 문서입니다.

이 문서는 `onboarding-role-channel-plan.md`, `discord-permission-setup-guide.md`, `onboarding-operation-runbook.md`를 기준으로 작성했습니다. 실제 Discord 역할/권한 설정, 봇 코드, 데이터는 변경하지 않습니다.

## 1. 사용 방법

아래 문구는 운영진이 Discord 공지 채널, 문의 채널, DM에서 복사해 사용할 수 있는 메시지 모음입니다.

일부 공지용 문구는 `/공지` 템플릿으로도 사용할 수 있습니다.

상황에 맞게 날짜, 시간, 채널명, 링크만 수정해 사용하면 됩니다. 실제 서버 구조, 운영진 최종 안내, 확정된 채널명에 따라 문구는 조정할 수 있습니다.

참여자에게 보이는 메시지는 따뜻하고 차분한 톤을 유지해 주세요. 처음부터 활발히 참여하지 않아도 괜찮고, 각자의 속도에 맞게 참여할 수 있다는 안내를 함께 남기는 것이 좋습니다.

민감한 상황, 안전이 걱정되는 내용, 개인적인 판단이 필요한 문의는 챗봇 답변으로 마무리하지 말고 운영진 문의로 연결해 주세요.

## 2. 입장 직후 환영 메시지

권장 채널: `#환영-인사와-규칙`, `#처음-안내`, 공지 채널

```text
프로젝트 리디파인 디스코드에 오신 것을 환영합니다.

처음 들어오면 낯설 수 있어요. 처음부터 모든 채널을 다 확인하거나 바로 대화에 참여하지 않아도 괜찮습니다.

먼저 `/안내`와 `/채널안내`를 확인해 주세요. 디스코드 안에서 무엇부터 보면 좋을지, 각 채널이 어떤 용도로 쓰이는지 안내받을 수 있습니다.

궁금한 점이 생기면 `/질문 내용: 궁금한 내용` 형식으로 물어볼 수 있어요.

예시:
`/질문 내용: 처음 왔는데 뭐부터 확인하면 되나요?`

온보딩 상황에 따라 보이는 채널은 사람마다 다를 수 있습니다. 보이는 채널이 적어도 문제가 있다는 뜻은 아니니, 지금 보이는 안내부터 천천히 둘러봐 주세요.

각자의 속도에 맞게 익숙해져도 괜찮습니다.
```

## 3. 0~24시간 안내 메시지

권장 채널: `#처음-안내`, `#프로젝트공지_일정및안내`, `#참여동의-확인`

```text
입장 후 첫 24시간은 서버에 천천히 적응하는 시간입니다.

먼저 참여동의 확인을 완료했는지 살펴봐 주세요. 이름표나 색상을 고르는 안내가 보이면 편한 것으로 선택하면 됩니다.

중요한 일정과 기본 안내는 공지 채널에서 확인할 수 있어요. 공지가 많아 보여도 처음부터 모두 외우지 않아도 괜찮습니다.

채팅에 바로 참여하기보다 둘러보기를 먼저 해도 괜찮아요. 읽기, 이모지 반응, 짧은 질문도 충분한 참여 방식입니다.

불편하거나 헷갈리는 부분이 있으면 운영진 문의 채널에 남겨 주세요. 운영진이 확인 후 순서대로 안내드리겠습니다.
```

## 4. 24~48시간 안내 메시지

권장 채널: `#처음-안내`, `#프로젝트공지_일정및안내`, `#자유채팅방`

```text
입장 후 24~48시간에는 디스코드 구조를 조금씩 익혀보면 좋습니다.

채널이 어디에 쓰이는지 헷갈리면 `/채널안내`를 사용해 주세요. 궁금한 점은 `/질문 내용: 궁금한 내용`으로 물어볼 수 있습니다.

공개 채팅이 부담스럽거나 개인적인 이야기가 포함된다면 익명고민채널이나 운영진 문의 채널을 이용해 주세요.

자유채팅이나 미션은 가능한 만큼만 참여하면 됩니다. 꼭 많이 말하거나 모든 활동에 참여해야 하는 것은 아니에요.

온보딩 중에는 보이는 채널이 사람마다 다를 수 있습니다. 채널이 적게 보여도 문제가 있다는 뜻은 아니며, 필요한 안내부터 순서대로 볼 수 있도록 운영하고 있습니다.
```

## 5. 48~72시간 안내 메시지

권장 채널: `#프로젝트공지_일정및안내`, `#처음-안내`, OT 안내 채널

```text
입장 후 48~72시간에는 OT 전 확인사항을 함께 살펴보겠습니다.

공지된 일정, 준비물, 참여 방식 중 아직 헷갈리는 부분이 있다면 운영진 문의 채널에 남겨 주세요. 참여 방식이 부담되거나 조정이 필요하다고 느껴지는 부분도 편하게 알려주셔도 됩니다.

72시간 이후에는 운영진 확인을 거쳐 역할이나 보이는 채널이 조정될 수 있습니다. 모든 사람이 같은 속도로 전환되는 것은 아니며, 각자의 속도에 맞게 이어가기 위한 과정입니다.

처음부터 완벽하게 적응하지 않아도 괜찮습니다. 필요한 만큼 천천히 확인하고, 어려운 점은 운영진에게 알려 주세요.
```

## 6. 온보딩-천천히 역할 대상 안내 메시지

권장 채널: DM, `#처음-안내`, `#운영진-문의`

```text
지금은 천천히 적응하는 시간으로 생각해 주세요.

모든 활동 채널에 바로 참여하지 않아도 괜찮습니다. 공지와 안내를 읽어보고, 필요할 때 이모지 반응이나 짧은 질문을 남기는 것도 참여 방식입니다.

대화나 활동이 부담되는 날에는 보기만 해도 괜찮아요. 어려운 점이나 헷갈리는 부분이 있으면 운영진에게 직접 문의해 주세요.

운영진은 참여를 강요하기보다, 편한 속도로 적응할 수 있도록 안내하겠습니다.
```

## 7. 온보딩-기본 역할 대상 안내 메시지

권장 채널: DM, `#처음-안내`, `#프로젝트공지_일정및안내`

```text
지금 보이는 공지, 자유채팅, 미션 안내를 가볍게 확인해 주세요.

처음부터 말을 많이 하지 않아도 괜찮습니다. 읽기만 하거나, 가능한 날에만 반응해도 됩니다.

궁금한 점은 `/질문 내용: 궁금한 내용`으로 확인할 수 있고, 개인 상황이나 역할/채널 관련 문의는 운영진 문의 채널에 남겨 주세요.

가능한 만큼만 참여해도 괜찮습니다. 각자의 속도에 맞게 천천히 익숙해져 주세요.
```

## 8. 온보딩-활동 역할 대상 안내 메시지

권장 채널: DM, `#자유채팅방`, `#오늘의-미션`, `#매일출석체크`

```text
자유채팅, 챌린지, 출석, 포인트 관련 채널을 확인할 수 있습니다.

포인트와 랭킹은 경쟁이나 평가가 아니라 참여의 재미를 더하기 위한 요소입니다. 점수나 순위를 너무 신경 쓰지 않아도 괜찮아요.

활동이 많게 느껴지거나 부담되는 날에는 쉬어도 됩니다. 가능한 만큼만 참여해 주세요.

과한 친목이나 비교보다 서로의 속도를 존중하는 분위기를 함께 만들어 주세요.
```

## 9. 채널이 적게 보인다는 문의 대응 메시지

권장 채널: 운영진 문의 채널, DM

```text
문의해 주셔서 감사합니다.

채널이 적게 보이는 것은 문제가 아니라 72시간 온보딩 과정의 일부일 수 있습니다. 처음부터 너무 많은 채널을 한꺼번에 확인하지 않도록, 각자의 속도에 맞춰 필요한 채널부터 보이도록 운영하고 있어요.

시간이 지나면서 운영진 확인 후 역할이나 보이는 채널이 조정될 수 있습니다.

지금 보이는 안내로 이용하기 어렵거나 불편한 점이 있다면 알려 주세요. 운영진이 함께 확인하겠습니다.
```

## 10. 활동 채널이 부담될 때 안내 메시지

권장 채널: 운영진 문의 채널, DM

```text
활동 채널이 부담된다면 꼭 많이 참여하지 않아도 괜찮습니다.

미션, 포인트, 랭킹은 선택적으로 참여할 수 있는 요소입니다. 가능한 날에만 참여해도 되고, 부담되는 날에는 읽기만 해도 괜찮아요.

채널이 너무 많게 느껴지거나 참여 방식 조정이 필요하면 운영진에게 알려 주세요. 필요한 부분을 함께 확인하겠습니다.
```

## 11. 익명고민채널 사용 유도 메시지

권장 채널: `#익명고민채널`, `#처음-안내`, 운영진 문의 채널

```text
공개 채팅이 부담스럽다면 익명고민채널을 사용할 수 있습니다.

이름을 드러내기 어려운 질문이나 고민을 조금 더 편한 방식으로 남길 수 있는 공간입니다. 다만 모든 고민에 즉시 답변이 달리지는 않을 수 있어요.

위급하거나 안전이 걱정되는 내용은 익명 채널에만 남기지 말고 운영진에게 직접 알려 주세요.

타인을 특정하거나 비난하는 내용, 다른 사람의 개인정보가 포함된 내용은 피해주세요. 서로의 안전과 속도를 존중하는 방식으로 사용해 주세요.
```

## 12. 운영진 문의 유도 메시지

권장 채널: 공지 채널, `#운영진-문의`, DM

```text
개인적인 상황, 역할이나 보이는 채널과 관련된 문의는 운영진 문의 채널을 이용해 주세요.

답변이 바로 오지 않을 수 있지만, 남겨주신 내용은 운영진이 순서대로 확인하겠습니다.

처음부터 자세히 설명하지 않아도 괜찮습니다. 필요한 만큼만 알려주시면, 운영진이 확인 후 가능한 안내를 드릴게요.
```

## 13. 72시간 이후 참여자 역할 전환 안내

권장 채널: 공지 채널, `#프로젝트공지_일정및안내`, DM

```text
72시간 온보딩 기간 이후에는 운영진 확인을 거쳐 참여자 역할로 전환될 수 있습니다.

모든 사람이 같은 속도로 전환되는 것은 아닙니다. 역할 전환은 평가나 등급이 아니라, 각자에게 맞는 참여 환경을 조정하기 위한 과정입니다.

전환 이후에는 보이는 채널이 달라질 수 있습니다. 헷갈리거나 불편한 점이 있으면 운영진 문의 채널에 남겨 주세요.

앞으로도 가능한 만큼, 각자의 속도에 맞게 이어가면 됩니다.
```

## 14. 온보딩 연장 안내 메시지

권장 채널: DM, 운영진 문의 채널

```text
운영진 확인 결과, 온보딩 기간을 조금 더 이어가며 천천히 적응하는 방향으로 안내드리려고 합니다.

온보딩 연장은 불이익이 아닙니다. 조금 더 여유 있게 공지와 채널을 둘러보고, 필요한 안내를 받을 수 있도록 돕는 과정입니다.

필요한 경우 운영진이 추가 안내를 드리겠습니다. 부담되는 점이나 조정이 필요한 부분이 있으면 가능한 만큼만 알려 주세요.

각자의 속도에 맞게 이어갈 수 있도록 함께 확인하겠습니다.
```

## 15. 운영진 내부용 짧은 DM 템플릿

### 입장 확인

```text
안녕하세요. 리디파인 디스코드 입장 확인했습니다. 먼저 `/안내`와 공지 채널을 천천히 확인해 주세요.
```

### 공지 확인 여부 확인

```text
안녕하세요. 공지 채널의 기본 안내를 확인하셨는지 짧게 확인드립니다. 아직이면 편한 시간에 천천히 확인해 주세요.
```

### 채널이 잘 보이는지 확인

```text
현재 공지와 안내 채널이 잘 보이는지 확인 부탁드립니다. 보이지 않거나 헷갈리는 채널이 있으면 알려 주세요.
```

### 부담되는 점이 있는지 확인

```text
온보딩 중 부담되거나 헷갈리는 점이 있는지 확인드립니다. 자세히 말하기 어렵다면 짧게만 알려주셔도 괜찮습니다.
```

### 72시간 이후 역할 전환 안내

```text
72시간 온보딩 확인 후 참여자 역할 전환을 안내드립니다. 전환 이후 보이는 채널이 달라질 수 있으니 불편한 점이 있으면 알려 주세요.
```

### 온보딩 연장 안내

```text
조금 더 천천히 적응하실 수 있도록 온보딩 기간을 이어가려 합니다. 불이익은 아니며, 필요한 안내를 더 여유 있게 확인하기 위한 과정입니다.
```

## 17. 사용 시 주의사항

- 역할명과 채널 공개 범위를 공개적으로 비교하지 않습니다.
- 참여자에게 내부 분류나 설문 결과를 말하지 않습니다.
- 위기 표현이나 민감한 내용은 운영진이 직접 확인합니다.
- 챗봇이 상담이나 판단을 대신하지 않습니다.
- 공지 문구는 실제 운영진 안내와 서버 구조에 맞춰 조정합니다.
- 역할 전환과 온보딩 연장은 평가가 아니라 참여 환경을 맞추기 위한 운영 조정으로 안내합니다.
