## 2. 다음 개발 우선순위

**코드·자동 검증 완료 / 실환경 QA 대기 / 크기 중**

- 교환·인증·반응 후속 확인의 경과 시간과 지연 배지
- active 미션 마감 임박 표시

- 슬롯 선예약과 원자 이력으로 재시작 중복 방지
- 기본 off, 전용 채널 미설정 시 안전한 no-op
- 참여자 DM·공개 채널·자동 상태 변경 없음

기준: [운영 콘솔 마스터 플랜](ops-console-master-plan.md) 5.4절과 [Phase 3 작업 지시서](../prompts/codex/ops-reminder-v1.md).

코드 구현과 자동 검증은 완료했으며, 실제 Railway 단일 인스턴스·운영 채널·모바일 화면 QA 후 활성화한다.

### 완료 — 참여자 개인 운영 카드

운영자가 정확한 Discord 사용자 ID로 포인트·체크인·미션·교환 이력을 한 화면에서 확인하는 읽기 전용 기능이다. allowlist 응답, example 제외, 원문·첨부·메모 비노출, 파일 무변경을 자동 테스트로 검증했으며 실제 브라우저 QA는 대기 상태다.

### 완료 — 주간 운영 리포트

KST 주간 참여·지급·교환·대기 요약을 콘솔과 운영 채널에 생성한다. 집계·읽기 전용 콘솔·수동 발송·기본 off 자동 발송과 주차별 중복 방지 이력을 구현했으며 실제 Railway·Discord 채널·모바일 QA는 대기 상태다.

### 운영 데이터 축적 후 판단

운영 전 통합 점검 자동화 v1까지 코드와 고정 fixture 검증을 완료했다. 저녁 Railway 설정 전 `npm run check:prelaunch`, 설정 후 `npm run check:prelaunch -- --strict`를 실행하고 Discord·Railway 수동 목록을 함께 확인한다.

- FAQ/Knowledge fallback 개선: 실제 질문 로그가 쌓인 뒤
- 비동기 소셜 공지·응원 알림: 알림 피로와 사용량 확인 후
- 던전월드 10~12회차: 8~9회차 실사용 도달 확인 후
- 완전 자동 포인트 지급: 반자동 지급을 수 주 운영한 뒤
