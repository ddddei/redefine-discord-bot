# 웹게임 디자인 점검 보고서 (2026-07-03)

간식 세계관 웹게임 3종(`간식 맞추기` 매치3, `간식 공방 키우기` 방치형, `간식 수호대` 덱빌딩)의 시각 디자인·연출 현황 점검 결과입니다. 실제 브라우저 구동 스크린샷과 CSS 소스 분석을 기반으로 작성했습니다. `검은 종 생존전`은 다크 팔레트의 별개 결이라 이 점검·개선 트랙에서 제외합니다 (기존 명세 [dungeonworld-survivors-design-direction.md](dungeonworld-survivors-design-direction.md) 참고, 별도 트랙).

## 요약

| 항목 | 상태 |
| --- | --- |
| 색·타이포 토큰 | **양호** — 3종이 같은 파스텔 팔레트(`#fff7ec` 크림, `#ff8a5b` 주황 계열)와 같은 폰트 스택을 사용. 서로 미러링한 덕분 |
| 컴포넌트 일관성 | **미흡** — border-radius가 게임마다 8~24px로 제각각, 버튼/모달/헤더 구성이 게임마다 다름 |
| 레이아웃 패러다임 | **불일치** — 매치3만 문서형 페이지, 방치형·덱은 앱형 카드 |
| 연출(juice) | **부족** — 매치3·방치형은 최소한만 있음, **덱은 키프레임 애니메이션 0개** |

## 1. 토큰 레벨 (색·타이포) — 양호

3종 모두 `:root`에 같은 기반 토큰을 정의:

- 공통: `--surface-cream #fff7ec`, `--surface-panel #fff`, `--text-main #4a3524`, `--text-muted #8a7360`, `--accent-primary #ff8a5b`, `--border-soft #f1d9bd`, 동일 `--shadow-soft`, 동일 폰트 스택(`Apple SD Gothic Neo, Pretendard, Segoe UI`)
- 게임별 확장: 매치3 타일 6색, 방치형 `--accent-gold/danger`, 덱 `--accent-block/weak/vulnerable`

단, 각 파일에 **복붙으로 중복 정의**되어 있어 한 게임에서 수정하면 나머지와 어긋난다. 공용 파일로 승격이 필요.

## 2. 컴포넌트 레벨 — 미흡

- **border-radius 혼재**: 매치3 10~20px, 방치형 12~24px, 덱 8~16px + pill(999px). 같은 "카드"인데 게임마다 모서리가 다름.
- **버튼**: 세 게임 모두 `.button.primary/secondary` 클래스명은 공유하지만 정의가 파일마다 별도라 패딩·크기·호버가 미묘하게 다름.
- **헤더**: 매치3는 영문 오버라인("SNACK MATCH PUZZLE")+좌측 정렬 제목, 방치형은 직함+무대명+통계 칩, 덱은 게임명+체력 칩. 게임명·핵심 수치라는 같은 정보를 서로 다른 구조로 표현.
- **모달**: 방치형(오프라인 수익/승급/환생/리셋)과 매치3(결과)의 모달 스타일이 별도 구현.

## 3. 레이아웃 패러다임 — 불일치

- **매치3**: 세로로 긴 문서형 페이지 — 제목/설명 문단, 보드, 하단에 "진행 방법"·"점수 안내" 불릿 목록. 데스크톱에서 좌측 정렬.
- **방치형·덱**: 모바일 앱형 — 가운데 카드(480~520px), 상단 고정 헤더, (방치형은) 하단 탭 바.

같은 세계관의 자매 게임인데 매치3만 "웹 문서"처럼 보인다. 앱형 카드로 통일하고 도움말은 접이식으로 내리는 게 맞다.

## 4. 연출(juice) — 게임별 격차 큼

| 게임 | @keyframes | 평가 |
| --- | --- | --- |
| 매치3 | 3종 (tile-pop, tile-drop, tile-shake) | 기본기는 있음. 매치 점수 팝업(+30), 콤보 강조, 셔플 연출 없음 |
| 방치형 | 3종 (버튼 바운스, +N 팝업, 황금 간식 펄스) | 클릭 손맛은 있음. 승급 장면 전환·배달 완료·업적 달성 연출 없음 |
| 덱 | **0종** (transition 2건뿐) | 카드를 써도 화면이 조용함. 피격/피해 숫자/드로우/승패 전환 연출 전무 — 손맛 최하 |

공통적으로: 모달 열림/닫힘 트랜지션 없음(즉시 표시), 버튼 press 피드백 없음, `prefers-reduced-motion` 대응 없음.

## 5. 결론 (개선 우선순위)

1. **공용 디자인 시스템 파일 승격** — 토큰(색·타이포·radius 스케일·그림자)과 공통 컴포넌트(버튼·칩·모달·카드 패널·헤더)를 공용 CSS 한 벌로 만들어 3종이 로드. 중복 정의 제거.
2. **매치3 레이아웃을 앱형 카드로 개편** — 헤더 통일, 영문 오버라인 제거, 도움말 접이식.
3. **덱 연출 최우선 보강** — 카드 사용/피격/피해 숫자/드로우/승패 전환. 그다음 방치형(승급·배달·업적), 매치3(점수 팝업·콤보·셔플).
4. 공통 마감: 모달 트랜지션, 버튼 press, `prefers-reduced-motion`.

구체 실행 계획은 [webgame-design-refresh-plan.md](webgame-design-refresh-plan.md) 참고.
