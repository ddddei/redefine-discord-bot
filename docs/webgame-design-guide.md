# 웹게임 디자인 가이드 — 간식 세계관 비주얼 규칙 v1

간식 세계관 웹게임(매치3·방치형·덱, 이후 신작 포함)의 아트·모션 기준 문서입니다. 2026-07-04 스타일 시안 비교에서 **B안 "라인 캐릭터"** 가 선정되어 이 문서로 명문화합니다. 모든 신규 에셋과 화면은 이 가이드를 따릅니다. 배경 계획: [webgame-design-v2-plan.md](webgame-design-v2-plan.md).

## 0. 타겟 플랫폼

- 매치3(`public/match3/`)·방치형(`public/idle/`)·덱(`public/deck/`)은 **모바일 퍼스트**입니다. 주 진입로는 Discord 앱 내 브라우저이며, 375px 폭에서 핵심 조작이 엄지 존 안에 있어야 합니다.
- `검은 종 생존전`(`public/dungeonworld-survivors/`)은 고도화 v1(2026-07-06 - [survivors-improvement-plan.md](survivors-improvement-plan.md))부터 **데스크톱·모바일 겸용**입니다. 다크 판타지 톤은 이 문서의 간식 세계관 라인 캐릭터 스타일과 별개로 유지하며(3·4·6절 참고), 모바일 조작은 가상 스틱(화면 왼쪽 60% 영역)으로 처리해 이 문서의 엄지 존 규칙과는 다른 방식을 씁니다.

## 1. 일러스트 스타일 — 라인 캐릭터

스티커/이모티콘 감성. 굵은 초콜릿색 외곽선 + 플랫 파스텔 채색 + 또렷한 표정. 작은 크기(28px)에서도 형태와 표정이 읽히는 것이 최우선 기준.

### 1.1 외곽선 (스타일의 핵심)

- 색: `#4a3524` (UI 본문 텍스트 `--text-main`과 동일 — 화면과 에셋이 한 몸으로 보이게 하는 장치)
- 두께 (viewBox 64 기준): **주 실루엣 3.0** / 내부 구획·소품 2.4~2.8 / 표정 선(입 등) 2.2~2.3
- `stroke-linejoin="round"`, `stroke-linecap="round"` 필수. 뾰족한 조인트 금지.
- 외곽선 없는 요소는 하이라이트·볼터치·씨앗 같은 **채색 위 장식**뿐.

### 1.2 채색

- 면은 **플랫 단색**. 그라디언트·블러·드롭섀도 금지.
- 오브젝트당 본색 1 + 밝은 톤 1(하이라이트/배 부분) + 장식색 1~2까지. 그 이상 쓰지 않는다.
- 팔레트는 3절 서브 팔레트에서만 고른다.

### 1.3 표정 (캐릭터성의 핵심)

- 눈 (둘 중 하나로 통일감 있게):
  - **큰 눈**: 흰자 원 r 3.0~3.6 + 동공 `#4a3524` r 1.7~1.9 (캐릭터·적 기본)
  - **도트 눈**: `#4a3524` r 2.3~2.7 + 흰 글린트 r 0.9 (타일·소품용)
- 입: `#4a3524` stroke 2.2~2.3, round cap 곡선. 미소 기본.
- 볼터치: 핑크/피치 타원 rx≈3 ry≈2 (`#ff9fb3` 또는 `#e8a37c` 계열).
- **위압감 표현(정예·보스)**: 눈꼬리를 내린 반원 눈꺼풀, 一자 눈썹, 입 각도로 표현. 외곽선·팔레트 규칙은 유지 — "무섭게"가 아니라 "심술궂게".

### 1.4 형태·구도

- viewBox `0 0 64 64` 통일. 도형은 x/y 5~59 안에 배치 (여백 확보).
- 실루엣은 원·타원·둥근 사각 기반. 곡률 큰 라운드, 예각 금지.
- 덱 적은 등급별 화면 표시 크기 차등(일반 < 정예 < 보스)이므로 viewBox 안에서의 밀도는 동일하게, 표시 크기는 CSS로.

### 1.5 기준 에셋 (canonical — 새 에셋은 이 셋과 나란히 놓고 이질감 없어야 함)

- `public/shared/assets/match3-tile-strawberry.svg` — 타일(도트 눈) 기준
- `public/shared/assets/deck-enemy-crumb-ant.svg` — 적(큰 눈) 기준
- `public/shared/assets/shared-char-baker.svg` — 캐릭터 기준

## 2. 에셋 파일 규칙

- 위치: `public/shared/assets/` (기존 `/game/shared` 라우트로 서빙, 서버 변경 불필요)
- 파일명: `{scope}-{종류}-{이름}.svg` — scope는 `match3`/`idle`/`deck`/`shared`, 이름은 영문 케밥
- 형식: `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64" role="img">` + 첫 자식으로 한국어 `<title>`
- 색은 고정 hex (currentColor 미사용 — 팔레트가 곧 아이덴티티), 스크립트·외부 참조 금지
- 게임에서는 `<img src="../shared/assets/….svg" alt="">` 참조 기본 (장식이므로 alt 비움, 의미 전달이 필요하면 인접 텍스트로)

## 4. 모션 원칙 (v1 구현을 규칙으로 승격)

- 움직이는 순간은 **피드백**(입력 반응·피해·획득)과 **보상**(승급·달성·전환)뿐. 상시 루프 애니메이션은 황금 간식 등 "주목 요청" 요소에만.
- 지속시간: 피드백 300ms 이하, 보상·장면 전환 400ms 이하. 이징은 `--motion-ease`.
- 애니메이션은 입력을 블로킹하지 않는다 (완료 대기 금지, 필요하면 복제본으로 연출).
- 모든 애니메이션은 `prefers-reduced-motion: reduce`에서 꺼진다 (game-ui.css 말미 블록에 등록).

## 5. 크기·가독성 체크 기준

에셋 완성 판정 전 3단계 크기에서 확인:

| 크기 | 대응 화면 | 통과 기준 |
| --- | --- | --- |
| 84px | 덱 적, 방치형 캐릭터 | 표정·디테일 모두 선명 |
| 44px | 매치3 타일(데스크톱), 소품 | 표정 식별 가능 |
| 28px | 매치3 타일(모바일) | 실루엣과 본색으로 종류 구분 가능 |

## 6. v3 톤 층 — 스토리북 프레임 (2026-07-04 확정)

무드 시안 C안(스토리북) + 낡은 종이·트럼프 카드 물성. 프레임(배경·패널·카드·타이포)의 규칙이며, 일러스트 에셋은 별도의 래스터 원화 트랙([webgame-art-prompts.md](webgame-art-prompts.md))으로 교체 예정 — 교체 전까지 기존 SVG 에셋을 새 프레임 안에 그대로 사용한다.

### 6.1 팔레트 v3 (프레임용 — 게임 CSS는 이 토큰을 소비)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--paper` | `#efe3c8` | 기본 종이 배경 |
| `--paper-deep` | `#e9dab6` | 아트 창·인셋 영역 |
| `--paper-raised` | `#f7f0e1` | 카드·패널 표면 (종이보다 밝게) |
| `--ink` | `#3a2a1c` | 프레임 선·본문 텍스트 (기존 `--text-main`보다 어둡고 세피아) |
| `--ink-soft` | `#6d5a41` | 보조 텍스트 |
| `--accent-rose` | `#b06a72` | 주요 버튼·강조 (뮤트 로즈) |
| `--accent-rose-deep` | `#7d454c` | 버튼 눌림 밑면 |

기존 고채도 토큰(`--accent-primary` 주황 등)은 프레임에서 사용 중단(파일에는 유지 — 에셋·구버전 호환).

### 6.2 종이 질감 (래스터 없이)

- 그레인: `feTurbulence`(fractalNoise, baseFrequency 0.85, 2 octaves) + `feColorMatrix`로 세피아 알파(≈0.10) 노이즈. CSS `background-image`의 **data-URI SVG**로 공용 유틸 클래스(`gk-paper`)에 내장.
- 비네트: 가장자리로 갈수록 `--ink` 계열이 옅게 깔리는 radial-gradient 오버레이 (opacity ≈ 0.2).
- 성능: 그레인은 정적(애니메이션 금지), 큰 화면 1장 + 패널은 상속으로 충분.

### 6.3 잉크 프레임과 컴포넌트 마감

- **이중 프레임**: 외곽 2~2.4px `--ink` + 안쪽 0.8~1px `--ink` (간격 5~7px), 모서리에 대각 컷 마크. 화면 최외곽(`gk-stage`)과 주요 패널에 적용.
- **radius 하향**: 프레임·패널 3~10px (알약형 제거). 버튼 10~12px.
- **버튼**: 주 버튼 = `--accent-rose` 배경 + `box-shadow: 0 3px 0 --accent-rose-deep`(눌림 밑면), `:active`에서 `translateY(2px)` + 그림자 1px. 보조 버튼 = 종이 배경 + 1.3px 잉크 보더.
- **칩/배지**: 종이 배경 + 1.3px 잉크 보더, radius 8~9px.
- **모달**: `--paper-raised` + 이중 프레임, 백드롭은 잉크 세피아(rgba(58,42,28,0.5)).

### 6.4 카드 물성 (덱 게임)

- 카드 = 종이 그레인 + 비네트 + 이중 프레임(외곽 2px/내곽 0.8px) + radius 8~10px.
- 코스트 = 좌상단 **로제트 메달**: 이중 링 원, 세리프 숫자.
- 아트 창 = `--paper-deep` 배경의 사각 프레임(1.4px 잉크) — 래스터 원화가 오면 이 창에 `<img>` 교체.
- 이름 아래 **가는 룰 라인 + 다이아(◆) 장식**, 하단에 한글 분류 표기(`공격`/`방어`/`스킬`). (개정 2026-07-13, visual-polish v1: 영문 대문자 표기는 한국어 UI에서 유일한 영문 노출이라 폐기.)
- 정예급 구분: 외곽 프레임을 이중 → 삼중 또는 골드 잉크(`#8a6a2c`) 라인.

### 6.5 타이포그래피 (시스템 폰트 정책 유지)

- 디스플레이(게임명·카드명·모달 제목): `Georgia, 'Apple Myungjo', 'Nanum Myeongjo', Batang, serif` — 세리프 스택. letter-spacing 0.3~0.5px.
- 본문·수치: 기존 고딕 스택 유지 (가독성). 수치는 `font-variant-numeric: tabular-nums` 유지.
- 웹폰트 번들은 보류 (시스템 세리프로 시작, 아쉬우면 후속 결정).

### 6.6 게임별 적용 지침

- 공통: `gk-stage`(종이 배경+비네트+이중 프레임) 위에 화면 구성. 헤더는 세리프 게임명 + 잉크 보더 칩.
- 매치3: 보드를 잉크 프레임 트레이로, 잉크 1px 보더 유지. **단서(개정 2026-07-13, visual-polish v1)**: v3 원화가 전부 어두운 세피아 톤이라 종이 톤 틴트로는 종류 판별이 불가능해, 타일 틴트만 "고채도 배경 폐기" 조항의 예외로 서브 팔레트 본색(3.2절)을 쓴다 — 원화 바깥 판별 링(≥4px)에만 보이는 구조. 판별 기능이 걸리지 않은 곳에는 여전히 본색 배경 금지.
- 방치형: 무대 장면 배경을 종이 그라디언트 톤으로 재조정(승급별 명도 변화 유지), 탭 바·목록 잉크 마감.
- 덱: 6.4 카드 물성 + 적 패널을 아트 창 구조로(원화 대비), 의도 배지 잉크 마감.
- 대비: `--ink` on `--paper` ≈ 7:1로 WCAG AA 충족. 로즈 버튼 위 텍스트는 `--paper-raised` 사용.

## 7. 카피와의 관계

비주얼이 귀여워져도 카피 톤은 기존 원칙(차분하고 직접적, 과장 금지) 유지. "귀여움은 그림이, 신뢰는 문장이" 담당한다.
