# 웹게임 디자인 가이드 — 간식 세계관 비주얼 규칙 v1

간식 세계관 웹게임(매치3·방치형·덱, 이후 신작 포함)의 아트·모션 기준 문서입니다. 2026-07-04 스타일 시안 비교에서 **B안 "라인 캐릭터"** 가 선정되어 이 문서로 명문화합니다. 모든 신규 에셋과 화면은 이 가이드를 따릅니다. 배경 계획: [webgame-design-v2-plan.md](webgame-design-v2-plan.md).

## 1. 일러스트 스타일 — 라인 캐릭터

스티커/이모티콘 감성. 굵은 초콜릿색 외곽선 + 플랫 파스텔 채색 + 또렷한 표정. 작은 크기(28px)에서도 형태와 표정이 읽히는 것이 최우선 기준.

### 1.1 외곽선 (스타일의 핵심)

- 색: `#4a3524` (UI 본문 텍스트 `--text-main`과 동일 — 화면과 에셋이 한 몸으로 보이게 하는 장치)
- 두께 (viewBox 64 기준): **주 실루엣 3.0** / 내부 구획·소품 2.4~2.8 / 표정 선(입 등) 2.2~2.3
- `stroke-linejoin="round"`, `stroke-linecap="round"` 필수. 뾰족한 조인트 금지.
- 외곽선 없는 요소는 하이라이트·볼터치·씨앗 같은 **채색 위 장식**뿐.

### 1.2 채색

- 면은 **플랫 단색**. 그라디언트·블러·드롭섀도 금지.
- 오브젝트당 본색 1 + 밝은 톤 1(하이라이트/배 부분) + 장식색 1~2까지. 그 이상 쓰지 않는다.
- 팔레트는 3절 서브 팔레트에서만 고른다.

### 1.3 표정 (캐릭터성의 핵심)

- 눈 (둘 중 하나로 통일감 있게):
  - **큰 눈**: 흰자 원 r 3.0~3.6 + 동공 `#4a3524` r 1.7~1.9 (캐릭터·적 기본)
  - **도트 눈**: `#4a3524` r 2.3~2.7 + 흰 글린트 r 0.9 (타일·소품용)
- 입: `#4a3524` stroke 2.2~2.3, round cap 곡선. 미소 기본.
- 볼터치: 핑크/피치 타원 rx≈3 ry≈2 (`#ff9fb3` 또는 `#e8a37c` 계열).
- **위압감 표현(정예·보스)**: 눈꼬리를 내린 반원 눈꺼풀, 一자 눈썹, 입 각도로 표현. 외곽선·팔레트 규칙은 유지 — "무섭게"가 아니라 "심술궂게".

### 1.4 형태·구도

- viewBox `0 0 64 64` 통일. 도형은 x/y 5~59 안에 배치 (여백 확보).
- 실루엣은 원·타원·둥근 사각 기반. 곡률 큰 라운드, 예각 금지.
- 덱 적은 등급별 화면 표시 크기 차등(일반 < 정예 < 보스)이므로 viewBox 안에서의 밀도는 동일하게, 표시 크기는 CSS로.

### 1.5 기준 에셋 (canonical — 새 에셋은 이 셋과 나란히 놓고 이질감 없어야 함)

- `public/shared/assets/match3-tile-strawberry.svg` — 타일(도트 눈) 기준
- `public/shared/assets/deck-enemy-crumb-ant.svg` — 적(큰 눈) 기준
- `public/shared/assets/shared-char-baker.svg` — 캐릭터 기준

## 2. 에셋 파일 규칙

- 위치: `public/shared/assets/` (기존 `/game/shared` 라우트로 서빙, 서버 변경 불필요)
- 파일명: `{scope}-{종류}-{이름}.svg` — scope는 `match3`/`idle`/`deck`/`shared`, 이름은 영문 케밥
- 형식: `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64" role="img">` + 첫 자식으로 한국어 `<title>`
- 색은 고정 hex (currentColor 미사용 — 팔레트가 곧 아이덴티티), 스크립트·외부 참조 금지
- 게임에서는 `<img src="../shared/assets/….svg" alt="">` 참조 기본 (장식이므로 alt 비움, 의미 전달이 필요하면 인접 텍스트로)

## 4. 모션 원칙 (v1 구현을 규칙으로 승격)

- 움직이는 순간은 **피드백**(입력 반응·피해·획득)과 **보상**(승급·달성·전환)뿐. 상시 루프 애니메이션은 황금 간식 등 "주목 요청" 요소에만.
- 지속시간: 피드백 300ms 이하, 보상·장면 전환 400ms 이하. 이징은 `--motion-ease`.
- 애니메이션은 입력을 블로킹하지 않는다 (완료 대기 금지, 필요하면 복제본으로 연출).
- 모든 애니메이션은 `prefers-reduced-motion: reduce`에서 꺼진다 (game-ui.css 말미 블록에 등록).

## 5. 크기·가독성 체크 기준

에셋 완성 판정 전 3단계 크기에서 확인:

| 크기 | 대응 화면 | 통과 기준 |
| --- | --- | --- |
| 84px | 덱 적, 방치형 캐릭터 | 표정·디테일 모두 선명 |
| 44px | 매치3 타일(데스크톱), 소품 | 표정 식별 가능 |
| 28px | 매치3 타일(모바일) | 실루엣과 본색으로 종류 구분 가능 |

## 6. 카피와의 관계

비주얼이 귀여워져도 카피 톤은 기존 원칙(차분하고 직접적, 과장 금지) 유지. "귀여움은 그림이, 신뢰는 문장이" 담당한다.
