# 검은 종 생존전 고도화 백로그

`public/dungeonworld-survivors/`(뱀서류 로그라이크)의 고도화 방향 문서입니다. 시각 판단 기준은 [dungeonworld-survivors-design-direction.md](dungeonworld-survivors-design-direction.md)(문제 6개 정의됨)가 기준이고, 이 문서는 그것을 포함한 **전체 고도화 단계와 선행 결정**을 다룹니다. 착수 시 항목별 계획서를 따로 만듭니다 ([next-work-roadmap-2026-07.md](next-work-roadmap-2026-07.md) 9절).

## 0. 현재 상태 (2026-07-05 점검)

- 콘텐츠 깊이는 4종 웹게임 중 최고: 직업 6종·무기 진화 6종·빌드 시너지·엘리트/보스 패턴·런 목표. 30분 정식 런 + 10분 퀵(`?mode=quick`) + 4분 데모.
- **Discord 연동(GameLink) 미적용** — 4종 중 유일. 랭킹·오늘의 도전 대상 아님.
- **데스크톱 전용** (방향키/WASD). 주 진입로가 Discord 인앱 모바일이라 참여자 접점이 구조적으로 작음.
- 디자인은 절차형 캔버스 + 일부 PNG 폴백. 클래스 스프라이트 지시서(`prompts/codex/survivors-class-sprites-v1.md`) 존재. 스토리북 v3 톤과 별개의 다크 판타지 톤.
- 결과 저장 없음(메타 진행 없음) — 재도전 동기 약함(방향서 1.6).

## 1. 선행 결정 2가지 (고도화 착수 전에 정해야 함)

### 결정 A — 모바일 지원 여부

| 선택지 | 내용 | 판단 재료 |
| --- | --- | --- |
| A-1 데스크톱 전용 유지 | 현행. 고도화는 데스크톱 경험만 다듬음 | 참여자 접점 작음 유지. 투자 대비 도달률 낮음 |
| A-2 모바일 조작 추가 | 가상 스틱(왼손) + 자동 공격은 이미 자동. 뷰포트·성능 재작업 동반 | 뱀서류는 모바일에서 검증된 장르. 단 2400×1600 맵 + 다수 개체 캔버스 렌더가 저사양에서 버틸지 **성능 실측 선행 필수** |

권장: **A-2를 목표로 하되, 착수 전 저사양 프로파일(CPU 4x 스로틀) 성능 실측으로 게이트**. 실측 탈락 시 A-1 확정하고 투자 규모를 낮춘다.

### 결정 B — 기본 세션 길이

30분 정식 런은 참여자 맥락(가벼운 접점·침대에서 한 손)과 마찰이 크다. 권장: **10분 퀵 런을 기본 URL로 승격**, 30분은 `?mode=long`으로 이동(도전 콘텐츠화). 밸런스는 퀵 런 구조가 이미 있으므로 기본값 교체 + 안내 문구 수준.

## 2. 고도화 단계 (권장 순서)

### S1 — 전투 체감 (방향서 1.1~1.4 구현) [효과 큼 / 중]

- 피격·처치·경험치·레벨업·상자·진화의 피드백 분리(히트 플래시, 처치 팝, 데미지 숫자 옵션, 짧은 정지 프레임)
- 위험 전조와 배경의 시각 분리(전조 전용 색/형태/애니메이션)
- 보스 전용 등장 경고·체력바·패턴명 표시
- 캐릭터/적 실루엣 구분 강화 — 클래스 스프라이트 지시서 재활용 + 적 스프라이트 확장
- 소리·진동 금지 정책 유지(전 게임 공통) — 타격감은 순수 시각으로

### S2 — 세션 구조 개편 (결정 B 반영) [효과 큼 / 소]

- 퀵 런 기본화, 결과 화면에 "다음 목표" 제시(방향서 1.6의 절반)
- 런 목표를 퀵 런 기준으로 재조정

### S3 — 메타 진행 (localStorage) [효과 큼 / 중]

- 런 종료 시 해금 포인트 → 시작 보너스/새 직업 변형/도전 과제 도감 (idle의 업적 도감 패턴 재사용)
- 방향서 1.6의 완성. 저장 스키마는 다른 게임과 동일하게 버전 필드 포함

### S4 — Discord 연동 + 랭킹 [중 / 소~중]

- `GameLink` 적용: 런 점수화(예: 생존 초 + 처치 수 가중 + 보스 격파 보너스 — 공식은 계획서에서 확정), `GAME_DEFINITIONS`에 survivors 추가(rankable, maxScore 상한)
- 오늘의 도전 편입 여부는 별도 판단 — 실시간 게임이라 시드 결정성이 약함(입력 타이밍 의존). **일일 랭킹은 가능하되 "같은 판" 보장은 불가**함을 명시하고, v1은 주간 랭킹만 권장
- 데스크톱 전용이 유지되면 랭킹 참여 접점이 작다는 점을 우선순위에 반영 (결정 A와 결합)

### S5 — 디자인 톤 정리 [하 / 중]

- 스토리북 v3(간식 3종)과 다크 판타지(생존전)의 이원 톤을 공식화할지, 생존전도 회화 원화 트랙으로 톤을 끌어올릴지 결정. 방향서 2절의 다크 판타지 방향 유지 권장(세계관이 다름) — 단 품질 기준(원화·프레임 밀도)은 v3 수준으로

## 3. 하지 않기로 확인한 것

- 사운드(합성음 포함) — 전 게임 무음 정책과 충돌. 재론 시 정책부터
- 실시간 협동/대전 — 아키텍처 범위 밖
- 서버 저장 메타 진행 — localStorage로 충분, 연동 v1 원칙(게임은 익명으로도 전부 플레이 가능) 유지

## 4. 착수 게이트

- S1·S2는 즉시 가능 (계획서부터)
- S3는 S2 이후 권장 (세션 길이가 메타 밸런스의 전제)
- S4는 결정 A 이후 권장
- 성능 실측(결정 A 게이트)은 QA 단독 작업으로 먼저 뺄 수 있음 — 결과가 모든 우선순위를 바꿈
