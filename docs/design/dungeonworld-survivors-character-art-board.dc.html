수치 Spline Sans Mono
공통 픽셀 규칙 — 6직업 전부 적용
해상도 · 스케일
64×64 캔버스에 제작, 실제 몸체 약 48px. 1px 어두운 외곽선. 그림자 타원은 별도 레이어.
시점
탑다운 3/4뷰, 카메라 아래쪽을 보는 정면 대기 포즈. 윗부분에서 역할이 읽혀야 함.
채도 규율
낮은 채도·녹슨 재질감. 밝은 광원은 핵심부 1점에만. 전체 글로우 금지.
실루엣 우선
색을 빼도 직업이 구분돼야 함. 어두운 몸체 + 직업 고유 소품으로 식별.
