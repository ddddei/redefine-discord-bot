# 운영용 기본 미션/상점 설계

실제 운영 시작 전 `/미션관리`, `/상점관리`, `/포인트관리`, `/교환관리`, `/운영현황`, `/admin`을 사용할 때 기준으로 삼는 기본 운영 항목 설계 문서입니다. 이 문서는 운영자가 직접 Discord 명령어로 등록할 값을 정리하며, 운영 데이터를 자동 생성하지 않습니다.

## 1. 문서 목적

- 운영 전 등록할 기본 미션과 권장 포인트를 정합니다.
- 운영 전 등록할 기본 상점/교환 항목과 노출 상태를 정합니다.
- 포인트가 경쟁 점수가 아니라 참여 기록이라는 운영 원칙을 정리합니다.
- 미션 인증, 교환, 취소, 환불 안내 문구를 참여자 친화적으로 정리합니다.
- 운영 전 `/미션관리`, `/상점관리`, `/운영현황`, `/admin`에서 확인할 순서를 제공합니다.

## 2. 운영 전제

- 참여자는 `/안내`, `/포인트`, `/상점`, `/교환`, `/체크인`, `/미션`, `/인증`을 사용합니다.
- 기본 미션 인증은 미션 인증 채널에 글, 사진, 영상 메시지를 올리고 운영자가 승인 반응을 누르는 방식입니다.
- `/인증`은 직접 제출이 필요한 경우의 보조 흐름입니다.
- 운영자는 `/운영현황`, `/포인트관리`, `/교환관리`, `/인증관리`, `/포인트로그`, `/미션관리`, `/상점관리`, `/운영내보내기`, `/admin`을 사용합니다.
- `/admin`은 읽기 전용입니다. 승인, 반려, 포인트 처리, 미션/상점 수정은 Discord 명령어에서 처리합니다.
- 실제 운영 데이터는 `data/*.local.json`에 저장될 수 있으며 커밋하지 않습니다.
- `data/*.example.json`은 테스트용이며 운영 대시보드에서는 실제 운영 데이터처럼 보이지 않도록 제외됩니다.

## 3. 포인트 운영 원칙

- 포인트는 경쟁 점수나 평가가 아니라 참여자가 남긴 활동 기록으로 안내합니다.
- 미션은 강제 과제가 아니라 선택형 활동입니다.
- 적은 포인트 미션은 참여 시작을 돕는 용도로 사용하고, 높은 포인트 미션은 실제 활동 기록이나 회고처럼 운영자 확인이 필요한 활동에 배정합니다.
- 반복 미션은 하루 1회, 주 1회처럼 운영자가 설명할 수 있는 단순한 기준을 우선합니다.
- 사진, 영상 인증은 참여자가 불편하지 않은 범위에서만 요청합니다.
- 얼굴, 주소, 연락처, 민감한 사적 정보가 포함되지 않도록 사전에 안내합니다.
- 청년동 포인트 전환은 운영 초기에는 기본적으로 한도 없이 열어 두는 것을 권장합니다.
- 30만원 이상처럼 비정상적으로 크거나 운영자가 확인하기 어려운 교환 신청은 별도 확인 후 처리할 수 있습니다.

## 5. 미션별 권장 포인트와 기준

### M001. 첫 인사 남기기

- 목적: 참여자가 서버에 들어와 처음으로 안전하게 말을 걸어볼 수 있게 합니다.
- 권장 포인트: 20P
- 인증 방식: 지정 채널에 자기소개 또는 첫 인사를 작성하고 운영자가 확인합니다.
- 반복 가능 여부: 1회
- 운영자 확인 기준: 인사, 현재 기분, 관심 활동, 기대하는 점 중 하나 이상이 자연스럽게 담겨 있으면 승인합니다.
- 참여자 안내 문구:

```txt
처음 오셨다면 가볍게 인사를 남겨 주세요.
길게 쓰지 않아도 괜찮아요.
지금의 기분, 관심 있는 활동, 기대하는 점 중 하나만 적어도 충분합니다.
```

### M002. 오늘의 체크인

- 목적: 참여자가 하루 상태를 가볍게 기록합니다.
- 권장 포인트: 10P
- 인증 방식: `/체크인`
- 반복 가능 여부: 하루 1회
- 운영자 확인 기준: 자동 기록을 기본으로 하되, 비정상적인 반복이나 테스트 데이터는 운영자가 점검합니다.
- 참여자 안내 문구:

```txt
오늘의 상태를 짧게 남겨 주세요.
기분, 컨디션, 오늘 해보고 싶은 것 중 하나만 적어도 괜찮아요.
```

### M003. 관심 활동 선택하기

- 목적: 참여자가 본인에게 맞는 활동 방향을 고르게 합니다.
- 권장 포인트: 20P
- 인증 방식: 지정 채널에 관심 활동을 작성합니다.
- 반복 가능 여부: 1회 또는 운영 회차별 1회
- 관심 활동 예시: 대화, 게임, 글쓰기, 산책, 취미 공유, 창작, 진로 탐색, 가벼운 모임
- 운영자 확인 기준: 하나 이상의 관심 활동이 확인되면 승인합니다.
- 참여자 안내 문구:

```txt
관심 있는 활동을 하나 이상 골라 남겨 주세요.
정답을 고르는 것이 아니라, 내가 편하게 시작할 수 있는 방향을 찾는 활동이에요.
```

### M004. 미션 인증 사진/영상 올리기

- 목적: 참여자가 실제 활동을 기록합니다.
- 권장 포인트: 30P
- 인증 방식: 미션 인증 채널에 사진 또는 영상 업로드, 운영자 승인 반응
- 반복 가능 여부: 활동별 1회 또는 운영자가 공지한 횟수
- 운영자 확인 기준: 활동과 관련된 기록이면 승인합니다. 얼굴, 주소, 연락처 등 민감정보가 보이면 공개 확산을 막고 보완 안내를 우선합니다.
- 참여자 안내 문구:

```txt
활동을 사진이나 영상으로 짧게 남겨 주세요.
얼굴, 주소, 연락처처럼 개인 정보가 보이지 않게 올려 주세요.
불편한 인증은 하지 않아도 괜찮습니다.
```

### M005. 프로그램 참여 후기 남기기

- 목적: 참여자가 활동 후 느낀 점을 정리합니다.
- 권장 포인트: 50P
- 인증 방식: 후기 채널 또는 지정 채널에 작성하고 운영자가 확인합니다.
- 반복 가능 여부: 프로그램 또는 회차별 1회
- 운영자 확인 기준: 좋았던 점, 아쉬웠던 점, 다음에 해보고 싶은 것 중 하나 이상이 담겨 있으면 승인합니다.
- 참여자 안내 문구:

```txt
참여 후 느낀 점을 짧게 남겨 주세요.
좋았던 점, 아쉬웠던 점, 다음에 해보고 싶은 것 중 하나만 적어도 됩니다.
```

### M006. 운영진에게 질문 남기기

- 목적: 참여자가 궁금한 점을 안전하게 물어볼 수 있게 합니다.
- 권장 포인트: 0P 또는 10P
- 인증 방식: 질문 채널 또는 `/질문` 흐름
- 반복 가능 여부: 제한 필요
- 운영자 확인 기준: 포인트 지급 대상이라면 실제 궁금한 점이 담긴 질문만 인정합니다.
- 운영 메모: 질문은 참여 안전망에 가까우므로 기본 미션보다는 안내성 활동으로 둘 수 있습니다.

### M007. 주간 회고 남기기

- 목적: 참여자가 한 주의 변화를 기록합니다.
- 권장 포인트: 40P
- 인증 방식: 지정 채널 작성
- 반복 가능 여부: 주 1회
- 운영자 확인 기준: 이번 주에 해본 것, 느낀 점, 다음 주에 해보고 싶은 것 중 하나 이상이 담겨 있으면 승인합니다.
- 참여자 안내 문구:

```txt
이번 주를 짧게 돌아봐 주세요.
잘한 일을 자랑해도 좋고, 아직 어려운 점을 적어도 괜찮아요.
```

### M008. 함께 응원하기

- 목적: 다른 참여자의 글에 긍정적 반응을 남깁니다.
- 권장 포인트: 10P
- 인증 방식: 운영자가 댓글 또는 반응을 수동 확인합니다.
- 반복 가능 여부: 하루 또는 주 단위 제한
- 운영자 확인 기준: 의미 있는 응원, 질문, 공감 표현만 인정합니다. 단순 도배는 제외합니다.
- 운영 메모: 운영 초반에는 paused로 두고 분위기가 안정된 뒤 활성화합니다.

## 6. 미션 인증 방식

- 미션 인증 채널 업로드: 글, 사진, 영상 인증을 올리고 운영자가 승인 반응으로 확인합니다.
- `/인증` 보조 제출: 채널 업로드가 어렵거나 텍스트 제출이 필요한 미션에 사용합니다.
- 운영자 확인: `/운영현황`, `/인증관리`, 반응 승인 기록, `/포인트로그`로 지급 여부를 확인합니다.
- 민감정보 처리: 참여자가 불편한 인증을 하지 않아도 되며, 개인정보가 포함된 경우 삭제나 재제출을 안내합니다.

## 8. 교환/취소/환불 안내 문구

### 교환 신청 전 공통 안내

```txt
교환 신청 전 포인트와 교환 항목을 꼭 확인해 주세요.
신청이 접수된 뒤에는 단순 변심으로 인한 취소나 환불이 어려울 수 있어요.
다만 중복 신청, 시스템 오류, 운영자 확인이 필요한 경우에는 운영진이 확인 후 조정할 수 있습니다.
상품별로 준비된 수량이 다를 수 있으니 신청 전 안내를 함께 확인해 주세요.
```

### 청년동 포인트 전환 안내

```txt
청년동 포인트 전환은 외부 상품권이나 현금 환급이 아니라, 청년동 안에서 사용할 수 있는 포인트 전환 신청입니다.
전환 신청 전 현재 포인트와 신청 수량을 확인해 주세요.
30만원 이상처럼 과도하게 큰 신청이나 확인이 필요한 신청은 운영진이 별도로 확인할 수 있습니다.
```

### 수량 제한 상품 안내

```txt
일부 상품은 준비된 수량이 정해져 있을 수 있어요.
신청이 몰리면 먼저 접수된 순서와 운영 기준에 따라 처리됩니다.
지급 가능 여부가 확정된 상품만 신청할 수 있도록 안내하겠습니다.
```

### 예외 처리 기준

- 단순 변심으로 인한 취소/환불은 기본적으로 어렵다고 안내합니다.
- 운영 오류, 시스템 오류, 중복 신청, 잘못된 지급은 운영자 판단으로 취소 또는 환불완료 처리할 수 있습니다.
- 예외 처리는 `/교환관리`와 `/포인트로그`에 기록이 남도록 처리합니다.

## 9. 운영 전 등록 순서

1. 실제 운영 채널과 미션 인증 채널이 준비됐는지 확인합니다.
2. `/미션관리`로 M001, M002, M003, M004를 우선 등록합니다.
3. 운영 일정이 확정됐으면 M005, M007을 등록하거나 paused 상태로 준비합니다.
4. M006, M008은 운영 방식이 정해진 뒤 paused 또는 hidden 성격으로 관리합니다.
5. `/상점관리`로 S001을 우선 등록하고 active 상태로 둡니다.
6. 필요하면 S002를 등록하되, 100P 항목만으로 충분하면 초기에는 숨깁니다.
7. S003, S004, S005는 실제 지급 가능 여부, 수량, 유효기간이 확정된 뒤 활성화합니다.
8. `/미션`, `/상점`에서 참여자 화면이 자연스럽게 보이는지 확인합니다.
9. `/운영현황`과 `/admin`에서 활성 미션 수와 활성 상점 항목 수를 확인합니다.
10. 교환 신청 테스트 후 `/교환관리`, `/포인트로그`, `/admin` 교환 대기 표시를 확인합니다.
