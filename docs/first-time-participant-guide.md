# 처음 참여자 안내

## 1. 이 공간은 무엇인가요?

리디파인 디스코드는 공지, 일정, 질문, 미션, 포인트, 상점 이용을 한곳에서 확인하는 공간입니다. 모든 활동을 한 번에 다 해야 하는 곳이 아니라, 지금 가능한 만큼 살펴보고 참여하면 됩니다.

## 2. 처음에는 무엇을 하면 되나요?

처음에는 `/안내`만 기억해도 충분합니다. `/안내`를 실행한 뒤 `🌱 처음 왔다면 여기부터` 버튼을 누르면 본인에게만 보이는 시작 가이드가 열립니다.

시작 가이드에서는 아래 순서만 확인하면 됩니다.

1. `#참여동의-확인`처럼 운영진이 안내한 참여동의 확인 채널을 먼저 봅니다.
2. 이름표나 색상 선택 채널에서 나를 편하게 알아볼 수 있는 표시를 고릅니다.
3. `/안내` 메뉴에서 오늘의 미션, 포인트, 상점/교환, 미니게임, 문의 방법을 살펴봅니다.
4. `오늘의 미션 보기` 버튼으로 오늘 할 수 있는 활동과 인증 방법을 확인합니다.
5. `내 포인트 확인`, `미니게임`, `상점/교환`은 필요할 때 천천히 확인합니다.

처음엔 여기까지만 해도 충분합니다. 포인트와 미니게임, 상점은 필수 과제가 아니라 선택 활동입니다.

처음에 함께 기억하면 좋은 명령어는 아래 정도입니다.

- `/안내`: 전체 사용법을 메뉴로 확인
- `/체크인`: 오늘의 상태를 가볍게 기록
- `/미션`: 참여 가능한 활동 확인
- `/포인트`: 내 여정 포인트 확인
- `/상점`: 교환 가능한 항목 확인

`/교환`과 `/인증`도 사용할 수 있지만, 처음부터 외울 필요는 없습니다.

## 3. 미션은 어떻게 참여하나요?

미션은 가능한 범위에서 참여하는 선택형 활동입니다.

1. `/미션`으로 참여 가능한 미션을 확인합니다.
2. 미션 인증 채널에 글, 사진, 영상을 올립니다.
3. 운영진이 확인 후 ✅ 반응을 누릅니다.
4. 승인되면 여정 포인트가 지급됩니다.
5. 지급 여부는 DM 또는 `/포인트`에서 확인합니다.

직접 제출이 필요한 경우에는 `/인증` 명령어를 보조 방법으로 사용할 수 있습니다.

## 4. 포인트는 어떻게 확인하나요?

`/포인트`를 입력하면 내 여정 포인트를 확인할 수 있습니다. 여정 포인트는 경쟁이나 순위를 위한 점수가 아니라, 참여 흐름을 기록하는 작은 보상입니다.

## 5. 상점은 어떻게 이용하나요?

`/상점`에서 교환 가능한 항목을 볼 수 있습니다. 항목을 선택한 뒤 신청 전 내용을 한 번 더 확인하고, 신청을 완료하면 포인트가 차감됩니다. 단순 변심에 따른 취소나 환불은 어려울 수 있으니 신청 전 내용을 확인해 주세요.

## 6. 궁금한 점은 어디에 물어보나요?

가벼운 질문은 `/질문`으로 물어볼 수 있습니다. 운영진 확인이 필요한 내용이나 개인적인 문의는 운영진 문의 채널을 이용해 주세요. 민감한 개인정보는 공개 채널에 자세히 남기지 않는 편이 좋습니다.

## 7. 꼭 기억할 것

처음부터 완벽하게 참여하지 않아도 됩니다. `/안내`를 먼저 열고, 오늘 가능한 만큼 체크인이나 미션을 살펴보면 충분합니다.

## 8. 운영자가 초대 전 확인할 문구

참여자를 초대하기 전에는 `/운영현황`의 `초대 전 점검`으로 운영 준비 상태를 확인하고, `참여자 초대 안내문`에서 짧은 공지와 자세한 첫 입장 안내를 확인할 수 있습니다. 자세한 운영자 확인 순서는 [운영자 허브 가이드](operator-dashboard-guide.md)의 초대 전 점검 모드를 참고합니다. 아래 문구가 실제 서버 채널명과 맞는지 확인해 주세요. 실제 채널 ID나 비공개 링크를 문서나 봇 안내에 넣지 않습니다.

```text
처음 들어오면 `/안내`를 실행하고 `🌱 처음 왔다면 여기부터` 버튼을 눌러 주세요.
먼저 참여동의 확인 채널을 보고, 이름표/색상 선택을 마친 뒤 오늘의 미션을 확인하면 됩니다.
포인트, 미니게임, 상점은 선택 활동이라 천천히 살펴봐도 괜찮아요.
궁금한 점은 운영진 문의 채널이나 `/질문`으로 남겨 주세요.
```

운영 전 QA에서는 테스트 참여자 계정으로 `/안내`를 실행해 시작 가이드가 private/ephemeral로 보이는지, `오늘의 미션 보기`, `내 포인트 확인`, `미니게임` 버튼으로 이어지는지 확인합니다.

초대 공지 자동 게시 기능은 아직 제공하지 않습니다. 이번 MVP에서는 운영자가 문구를 확인한 뒤 공지 채널에 직접 복사해 게시합니다.
