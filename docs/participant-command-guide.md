# 참여자 명령어 가이드

참여자 명령어는 안내, 질문, 참여 기록, 여정 포인트 확인, 교환 신청을 돕기 위한 기능입니다. 포인트는 경쟁이나 순위가 아니라 참여 흐름을 가볍게 돕는 선택형 장치로 설명합니다.

## 전체 목록

| 명령어 | 목적 | 사용 상황 | 응답 공개 범위 |
| --- | --- | --- | --- |
| `/안내` | 처음 온 참여자용 안내 확인 | 서버에 처음 들어왔거나 사용법이 헷갈릴 때 | 개인 안내 중심 |
| `/채널안내` | 주요 채널 용도 확인 | 어디에 글을 남길지 모를 때 | 개인 안내 중심 |
| `/질문` | FAQ/지식창고 질문 | 프로그램, 규칙, 문의 방법이 궁금할 때 | 개인 안내 중심, 미응답 질문은 운영 로그에 최소 기록 |
| `/리디` | 도움말, 일정, 규칙, 문의 안내 | 빠른 메뉴가 필요할 때 | 개인 안내 중심 |
| `/포인트` | 본인 여정 포인트 확인 | 현재 보유 포인트가 궁금할 때 | 본인만 확인 |
| `/상점` | 신청 가능한 항목 확인 | 교환 가능한 리워드를 보고 싶을 때 | private 응답 중심 |
| `/교환` | 포인트로 교환 신청 | 상점 항목 ID를 알고 신청할 때 | private 응답 중심 |
| `/체크인` | 오늘 체크인 기록 | 당일 참여 기록을 남길 때 | private 응답 중심 |
| `/미션` | 현재 미션 확인 | 참여 가능한 선택형 활동을 볼 때 | private 응답 중심 |
| `/인증` | 미션 수행 내용 제출 | 미션을 완료하고 운영자 검토를 요청할 때 | private 응답 중심 |

## 안내 문구 톤

- 참여자의 속도와 선택권을 존중합니다.
- 포인트를 경쟁, 순위, 평가처럼 설명하지 않습니다.
- 확인이 필요한 운영 정책은 단정하지 않고 운영진 안내를 기준으로 안내합니다.
- 개인정보나 민감한 사적 정보를 과하게 제출하지 않도록 안내합니다.

## `/안내`

- 처음 온 참여자가 Discord 사용 흐름과 기본 안내를 확인할 때 사용합니다.
- 온보딩 역할이 감지되면 역할에 맞는 보조 안내가 표시될 수 있습니다.
- 실제 채널 접근 권한은 Discord 역할 설정이 기준입니다.

## `/채널안내`

- 채널별 용도를 확인할 때 사용합니다.
- 어디에 질문을 남길지, 공지는 어디서 보는지 헷갈릴 때 안내합니다.
- 실제 채널 목록이나 권한은 운영진이 Discord 서버 설정에서 최종 확인합니다.

## `/질문`

- `내용`에 궁금한 점을 입력하면 FAQ를 먼저 찾고, 없으면 지식창고를 검색합니다.
- 답변을 찾지 못한 질문은 운영진이 FAQ 개선에 참고할 수 있도록 최소 정보로 기록될 수 있습니다.
- 민감하거나 개인적인 상황은 봇 답변보다 운영진 문의 채널을 우선합니다.

## `/리디`

- `도움`: 사용할 수 있는 명령어를 확인합니다.
- `일정`: 프로그램 일정 확인 방법을 봅니다.
- `규칙`: 커뮤니티 약속을 확인합니다.
- `문의`: 문의 방법을 확인합니다.

## `/포인트`

- 본인의 여정 포인트만 확인할 수 있습니다.
- 다른 참여자의 잔액이나 순위는 보여주지 않습니다.
- 포인트는 참여를 돕는 기록이며 경쟁 지표로 안내하지 않습니다.

## `/상점`

- 현재 신청 가능한 항목과 필요한 여정 포인트를 확인합니다.
- 본인이 필요할 때 직접 확인하는 방식입니다.
- 품절, 숨김, 일시중지 상태의 항목은 보이지 않을 수 있습니다.

## `/교환`

- `항목`에 상점 항목 ID를 넣어 교환을 신청합니다.
- 신청이 접수되면 필요한 여정 포인트가 차감되고 운영자 지급 확인을 기다립니다.
- 교환 신청 후 단순 변심 취소/환불은 원칙적으로 어렵습니다.
- 시스템 오류, 중복 신청, 운영진 사유 같은 예외 상황은 운영자가 취소 또는 환불 처리할 수 있습니다.

## `/체크인`

- 오늘의 참여 기록을 남길 때 사용합니다.
- 한국 시간 기준으로 하루 1회 지급됩니다.
- 체크인은 출석 압박이 아니라 가벼운 참여 기록으로 안내합니다.

## `/미션`

- 현재 참여 가능한 선택형 미션을 확인합니다.
- 미션마다 보상 포인트와 인증 필요 여부가 다를 수 있습니다.
- 모든 미션을 반드시 해야 하는 과제처럼 안내하지 않습니다.

## `/인증`

- `미션id`와 `내용`을 입력해 미션 수행 내용을 제출합니다.
- 제출 즉시 포인트가 지급되는 것이 아니라 운영자 승인 후 지급됩니다.
- 인증 내용은 확인에 필요한 최소한으로 작성합니다.
