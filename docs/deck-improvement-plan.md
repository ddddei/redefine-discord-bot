## 0. 완성 정의

1. 카드 30종(기존 18+신규 12)·유물 8종이 명세 수치대로 동작한다
2. 선형 11칸이 갈림길 맵(13층)으로 바뀌고 시드 결정적으로 생성된다
3. 이벤트 칸 10종이 동작한다
4. 오늘의 도전이 요일별 고정 시작덱 로테이션으로 돌아간다
5. 구버전 세이브 로드 시 크래시 없이 "새 여정을 준비했어요" 안내 후 새 런(통산 기록은 보존)
6. `check:release` 통과(로직 테스트 확장), maxScore 재산정, QA 통과

## 1. 작업 A — 신규 카드 12종

기존 태그 체계(힘/약화/취약 + 공격/방어) 위에 시너지 축 2개(연격·비축)를 추가한다. 수치는 1차안이며 구현 중 밸런스 플레이(시드 3개 풀런)로 조정 — 조정 결과를 보고서에 표로.

| 카드 | 비용 | 유형 | 효과 (1차안) |
| --- | --- | --- | --- |
| 크루아상 연타 | 1 | 공격·연격 | 피해 4. 이번 턴 사용한 공격 카드 수 × +2 |
| 마카롱 이중창 | 2 | 공격·연격 | 피해 5를 2회 |
| 슈크림 방벽 | 2 | 방어 | 방어도 8. 다음 턴에도 방어도 3 이월 |
| 티라미수 비축 | 1 | 스킬·비축 | 카드 2장 뽑기. 이번 턴 에너지 소모 없이 낸 카드가 있으면 1장 추가 |
| 캐러멜 응고 | 1 | 스킬 | 적에게 약화 2턴 |
| 박하 눈보라 | 2 | 공격 | 피해 3 + 취약 2턴 |
| 버터 기름칠 | 0 | 스킬·비축 | 에너지 +1. 소멸(런 중 1회성) |
| 프레첼 매듭 | 1 | 방어 | 방어도 5 + 힘 +1 |
| 잼 폭탄 | 3 | 공격 | 피해 14. 자신에게 약화 1턴 |
| 시나몬 각성 | 2 | 파워 | 매 턴 시작 시 힘 +1 (지속) |
| 도넛 순환 | 1 | 스킬 | 버린 더미에서 무작위(시드 RNG) 1장 손으로 |
| 꿀 코팅 | 2 | 파워 | 매 턴 시작 시 방어도 +3 (지속) |

- "파워(지속)" 유형은 신규 — 상태에 `powers: []` 필드 추가(저장 버전 상향 사유 1).
- 카드 보상 풀에 신규 12종 편입(가중치 균등). 카드 아트: v3 카드 창(`<img>`) 구조라 원화 12종 필요 — **원화 도착 게이트**([webgame-art-prompts.md](webgame-art-prompts.md) 형식으로 프롬프트 12종을 계획 승인 후 즉시 작성, 도착 전에는 기존 잉크 문양 폴백 렌더로 구현 진행 가능).

## 3. 작업 C — 갈림길 맵 (11칸 → 13층 분기)

### 3.1 구조

- 13층 세로 진행. 각 층 노드 1~3개, 층 간 연결은 인접 열로만. **시드 결정적 생성**: 층별 노드 수·타입·연결을 런 시드에서 파생한 전용 RNG 스트림으로 생성(전투 RNG와 콜 카운트 분리 — `rngCallCount` 재현 유지 방법을 명세: 맵 생성은 `createNewRun`에서 1회, 호출 횟수 고정 상한).
- 타입 분포 제약: 일반 전투 5~7, 정예 2(7층 이하 1·이상 1), 휴식 2(연속 층 금지), 이벤트 2~3, 보스 1(13층 고정). 1층은 항상 일반 전투.
- 점수 공식 갱신: `도달 층 × 1000 + 잔여 HP` 유지(층 수 11→13) → **maxScore = 13,060** (`GAME_DEFINITIONS.deck` 갱신 + 운영 문서 표).

### 3.2 UI

- 런 화면을 맵 화면으로 교체: 세로 스크롤 맵(엄지 존에서 다음 층 노드 탭), 현재 위치·방문 경로 표시. 노드 아이콘은 잉크 문양(전투/정예/휴식/이벤트/보스). 기존 "다음 칸으로" 버튼 제거 — 노드 탭이 진행.
- 오늘의 도전 시작 버튼은 맵 화면의 1층 진입 전에만 노출(진행 중 런 보호 — 기존 수정의 원칙 유지).

## 4. 작업 D — 이벤트 칸 10종

텍스트 선택지(2~3개) + 시드 결정적 결과. 던전월드 작법(차분한 존댓말, 위험 고지 명확) 재사용. 예시 전문은 콘텐츠 상수 `content.js`의 `EVENTS`로:

| 이벤트 | 선택지 요약 |
| --- | --- |
| 떠돌이 상인 | HP 8 지불 → 유물 / 카드 1장 제거 / 그냥 지나가기 |
| 버려진 오븐 | 카드 1장 강화(피해+3 또는 방어+3, 시드 선택) / 무시 |
| 설탕 샘 | HP 15 회복 / 최대 HP +5 (회복 없음) |
| 수상한 조각 케이크 | 무작위: 힘+2 또는 HP -10 / 무시 |
| 굶주린 아기 새 | 카드 1장 주기(제거) → 다음 전투 시작 시 적 HP -15 / 무시 |
| 낡은 지도 | 다음 층 노드 전부 공개(맵에 표시) / 무시 |
| 잊힌 창고 | 카드 보상 1회 / 유물 대신 저주 카드 1장 감수하고 유물 |
| 저주 카드 ‘눅눅한 빵’ | (위 결과물) 비용 1, 효과 없음, 소멸 불가 |
| 조용한 제단 | 저주·카드 1장 제거 / 무시 |
| 잠든 수호묘 | 깨우면 정예 전투 + 유물 확정 / 조용히 지나가기 |
