# 매치3 브라우저 미니게임: 간식 맞추기

`간식 맞추기`는 참여자들이 가볍게 시간을 보낼 수 있도록 만든 브라우저용 매치3 퍼즐입니다. 던전월드 세계관과는 무관한 독립 게임이며, 밝고 편안한 간식/디저트 테마를 사용합니다. `public/match3/` 아래의 정적 HTML/CSS/JS 파일로 동작하며, 기존 `검은 종 생존전`(`public/dungeonworld-survivors/`, [docs/dungeonworld-survivors-web-game.md](dungeonworld-survivors-web-game.md))과 동일한 운영 원칙과 서빙 구조를 따릅니다.

## 운영 원칙

- Discord 계정 연동이 없습니다.
- 포인트 지급 없음, 포인트 차감 없음, 베팅 없음, 랭킹 저장이 없습니다.
- 기존 버튼형 미니게임의 하루 보상 상한과 중복 지급 정책은 변경하지 않습니다.
- `.env` 수정이나 `npm run deploy`가 필요하지 않습니다.
- 결과는 브라우저 화면 안에서만 끝납니다. 운영 데이터 JSON에도 저장하지 않습니다.

## 플레이 내용

- 타일은 딸기 🍓, 오렌지 🍊, 사탕 🍬, 쿠키 🍪, 컵케이크 🧁, 젤리 🍇 여섯 종입니다. 색상뿐 아니라 이모지 형태로도 구분되어 색맹 접근성을 고려합니다.
- 보드는 8×8 그리드이며 DOM(버튼 그리드) + CSS로 렌더링합니다. 캔버스나 이미지 에셋은 사용하지 않습니다.
- 인접한 두 타일을 순서대로 클릭(또는 터치)하면 자리를 바꿉니다. 스왑 결과 3개 이상 일렬 매치가 없으면 자동으로 되돌립니다.
- 이동 30회 제한 스코어 어택 단일 모드입니다. 이동을 모두 쓰면 결과 화면에 최종 점수, 최고 콤보, 가장 많이 지운 타일, 짧은 평가 문구가 표시되고 `다시 하기` 버튼을 제공합니다.
- 점수 규칙: 3개 매치 30점, 4개 매치 60점, 5개 이상 또는 L·T자 매치 120점입니다. 연쇄(캐스케이드)가 이어질 때마다 배수가 ×1, ×2, ×3…으로 올라갑니다.
- 초기 보드는 매치가 이미 존재하지 않도록 생성됩니다. 매치가 사라지면 중력으로 아래로 떨어지고 위에서 새 타일이 채워지며, 다시 매치가 만들어지면 연쇄로 이어집니다.
- 가능한 스왑이 하나도 없으면 "간식을 새로 섞었어요" 안내와 함께 보드를 셔플합니다. 이때 이동 횟수는 차감되지 않습니다.
- URL에 `?seed=<숫자>`를 붙이면 시드 기반으로 결정적인 초기 보드가 생성됩니다. QA나 테스트에서 같은 보드를 재현할 때 사용합니다. 시드가 없으면 매번 랜덤한 보드로 시작합니다.

## 파일 구성

- `public/match3/index.html` — 마크업, 헤더(제목/남은 이동/점수/콤보), 보드 컨테이너, 도움말·결과 모달. 공용 디자인 시스템 `public/shared/game-ui.css`를 `styles.css`보다 먼저 로드합니다.
- `public/match3/styles.css` — 밝은 파스텔 팔레트, 타일별 배경색, 모바일 반응형 레이아웃
- `public/match3/board.js` — 순수 게임 로직(시드 가능한 RNG, 보드 생성, 매치 탐색, 스왑 검증, 제거/중력/리필, 연쇄 해석, 점수 계산, 셔플). DOM에 접근하지 않으며 `window.Match3Board` 전역과 Node `module.exports` 양쪽에서 로드할 수 있습니다.
- `public/match3/game.js` — DOM 렌더링, 클릭/터치 입력, 선택 상태 표시, 연쇄 애니메이션, 결과 모달 표시. 타일 아이콘은 `public/shared/assets/match3-tile-*.svg`([webgame-design-guide.md](webgame-design-guide.md))에 의존합니다.

## 로컬 실행 및 QA

봇 프로세스의 HTTP 서버가 켜져 있는 환경에서는 `/game/match3` 경로로 정적 파일을 서빙합니다. 이 경로는 대시보드 API와 달리 Basic Auth를 요구하지 않습니다.

`ADMIN_DASHBOARD_ENABLED=true`와 관리자 계정 환경 변수를 설정한 뒤 `npm start`로 봇을 실행하고, 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:3000/game/match3
http://localhost:3000/game/match3/?seed=42
```

확인할 사항:

- 스왑, 매치, 연쇄, 점수, 이동 횟수 차감이 동작하는지.
- 이동 30회를 모두 쓰면 결과 모달과 `다시 하기` 버튼이 나타나는지.
- `?seed=42`로 두 번 접속했을 때 같은 초기 보드가 나오는지.
- 모바일 뷰포트(375px)에서 보드가 화면 밖으로 잘리지 않는지.

## 배포 메모

정적 파일과 문서만 바뀐 경우에는 Slash Command 구조가 바뀌지 않으므로 `npm run deploy`를 실행하지 않습니다. 운영자가 실제 참여자에게 공개 URL을 안내하려면 먼저 Railway/정적 호스팅 경로에서 `public/match3/`가 접근 가능한지 확인해 주세요.
