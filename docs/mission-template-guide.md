# 미션 템플릿 운영 가이드

이 문서는 미션 템플릿과 요일별 오늘의 미션 MVP를 운영자가 이해할 수 있도록 정리한 안내 문서입니다. 템플릿은 반복해서 쓸 수 있는 미션 초안이며, `/운영현황`의 `미션 관리 허브`에서 확인하고 오늘 날짜의 active 미션으로 적용할 수 있습니다.

## 1. 파일 목적

`data/mission-templates.example.json`은 매일/오늘의 미션 UX 설계 문서에 맞춰 반복 미션과 특별 미션을 템플릿으로 정리한 안전한 예시 파일입니다. 운영자가 별도 `MISSION_TEMPLATES_DATA_PATH` 또는 `data/mission-templates.local.json`을 준비하지 않은 경우, 허브는 이 예시 파일을 읽기 전용 fallback으로 표시할 수 있습니다.

이 구조는 다음 용도로 사용합니다.

- 운영자가 어떤 미션을 기본 템플릿으로 준비할지 확인합니다.
- 월요일부터 금요일까지 요일별 기본 미션 흐름을 확인합니다.
- 템플릿을 선택해 오늘 날짜의 active 미션으로 적용합니다.
- 새 Slash Command 없이 기존 `/운영현황` 미션 관리 허브 안에서 운영합니다.

예시 파일에는 실제 Discord 채널 ID, 사용자 ID, 토큰, 비밀번호, 참여자 제출 내용을 넣지 않습니다. 실제 운영 템플릿을 분리하려면 local JSON이나 환경변수 경로를 사용합니다.

## 2. 미션 유형

| type | 의미 | 운영 기준 |
| --- | --- | --- |
| `daily_habit` | 매일 반복되는 작은 습관 미션 | 체크인, 한 줄 기록처럼 부담 없는 참여를 기본으로 둡니다. |
| `today_activity` | 운영자가 특정 날짜에 고르는 오늘의 활동 미션 | 템플릿 중 필요한 항목을 선택해 그날의 active 미션으로 적용합니다. |
| `relationship` | 관계/대화 미션 | 치료나 상담이 아니라 짧은 인사, 대화 기록, 관계 형성에 가까운 톤으로 운영합니다. |
| `reflection` | 회고 미션 | 평가가 아닌 기록이라는 톤을 유지합니다. |
| `special_event` | 게릴라/특별 미션 | 기간, 조건, 인증 기준이 복잡한 경우 기존 `/미션`, `/인증` 흐름과 함께 씁니다. |

## 3. 주요 필드

| 필드 | 설명 |
| --- | --- |
| `isExample` | 파일 전체가 예시 데이터임을 표시합니다. |
| `missionTemplates` | 운영자가 참고할 미션 템플릿 목록입니다. |
| `weekdayRecommendations` | 요일별 추천 템플릿 연결입니다. |
| `id` | 템플릿을 식별하는 예시 ID입니다. 실제 Discord ID가 아닙니다. |
| `key` | 운영자가 알아보기 쉬운 템플릿 키입니다. 예시에서는 `_example` suffix를 붙입니다. |
| `type` | `daily_habit`, `today_activity`, `special_event` 중 하나입니다. |
| `category` | 운영자가 묶어 볼 수 있는 분류입니다. 예: `checkin`, `photo`, `conversation`, `reflection`, `weekly_wrap`. |
| `recommendedDay` 또는 `weekday` | 추천 요일입니다. 예: `monday`, `tuesday`, `wednesday`, `thursday`, `friday`. |
| `title` | 참여자에게 보일 수 있는 미션명입니다. |
| `description` | 미션 목적과 인증 방식을 설명하는 문구입니다. |
| `rewardPoints` | 템플릿 적용 시 생성되는 미션의 지급 포인트입니다. |
| `defaultRewardPoints` | 호환용 기본 포인트 예시입니다. `rewardPoints`가 있으면 `rewardPoints`를 우선합니다. |
| `requiresSubmission` | `/미션` 또는 `/인증` 제출이 필요한지 여부입니다. 기본은 `true`입니다. |
| `submissionMode` | 인증 접수 방식입니다. 반복 미션은 보통 `channel_message`를 사용합니다. |
| `allowedAttachmentTypes` | 허용할 인증 형태 예시입니다. `text`, `image`, `video`를 조합합니다. |
| `rewardLimit` | 중복 지급 제한 기준입니다. 반복 미션은 하루 1회를 기본 예시로 둡니다. |
| `defaultChannelRef` | 실제 채널 ID가 아니라 `today_mission_channel` 같은 참조명입니다. |
| `status` | 템플릿 상태입니다. 허브 MVP에서는 `archived`가 아닌 템플릿을 후보로 표시합니다. |
| `note` 또는 `operatorNote` | 운영자가 안내 문구나 개인정보 주의사항을 확인하기 위한 메모입니다. |

## 4. 요일별 추천 운영 방식

기본 예시 방향은 다음과 같습니다.

| 요일 | 추천 방향 | 운영 톤 |
| --- | --- | --- |
| 월요일 | 가벼운 체크인/상태 확인 | 한 주를 시작하는 한 줄 참여 |
| 화요일 | 사진 인증 | 개인정보가 드러나지 않는 오늘의 장면 |
| 수요일 | 관계/대화 | 짧은 인사나 대화 기록 |
| 목요일 | 회고 | 평가가 아닌 기록 |
| 금요일 | 주간 정리 | 이번 주 참여와 다음 주에 해볼 일 |

운영자는 요일 추천을 그대로 쓰거나, 당일 분위기에 맞춰 다른 템플릿을 선택할 수 있습니다. 모든 문구는 치료, 상담, 평가처럼 보이지 않게 가벼운 참여와 관계 형성의 톤을 유지합니다.

## 5. 오늘의 미션 적용 방법

1. Discord에서 `/운영현황`을 실행합니다.
2. select 메뉴에서 `미션 관리 허브`를 선택합니다.
3. `요일별 추천`과 `오늘의 추천`을 확인합니다.
4. 템플릿 select 메뉴에서 적용할 템플릿을 선택합니다.
5. `템플릿을 오늘의 미션으로 적용` 버튼을 누릅니다.
6. 허브가 오늘 날짜의 active 미션을 만들고 목록에 다시 표시합니다.
7. 이미 오늘 날짜의 active 미션이 있으면 중복 생성하지 않고 기존 미션을 안내합니다.
8. `공지 미리보기`로 #오늘의-미션 채널에 올라갈 참여자용 안내를 확인합니다.
9. `오늘의 미션 게시`를 눌러 `TODAY_MISSION_CHANNEL_ID` 채널에 게시합니다.
10. 이미 같은 날짜에 게시된 기록이 있으면 봇이 중복 게시를 막습니다.

템플릿으로 만든 미션은 기존 `missions` 구조를 사용합니다. 따라서 기존 `/미션`, `/인증`, 승인/반려, 포인트 지급, Google Sheets append 흐름을 그대로 탑니다.

## 6. 자동 게시 보류

이번 MVP는 정해진 시간에 자동 게시하지 않습니다. 템플릿 적용은 active 미션을 저장하는 작업이고, Discord 채널 공지는 운영자가 미리보기 후 `오늘의 미션 게시` 버튼으로 직접 올립니다.

후속 작업 후보는 다음과 같습니다.

- 날짜별 템플릿 적용 이력 저장
- 운영자가 허용한 시간에만 자동 게시하는 스케줄러
- 공지 문구 세부 편집

## 7. 운영 시 주의사항

- 예시 템플릿을 실제 운영 데이터로 그대로 복사하지 않습니다.
- 실제 Discord 채널 ID, 사용자 ID, 메시지 ID, 역할 ID를 이 파일에 넣지 않습니다.
- 사진 인증 미션은 얼굴, 주소, 연락처, 지도 경로, 계정명 같은 개인정보가 드러나지 않도록 안내합니다.
- 반복 미션은 여러 번 제출할 수 있어도 포인트 지급은 같은 미션 기준 하루 1회라는 원칙을 분리해서 안내합니다.
- 새 Slash Command를 만들지 않고 기존 `/운영현황` 허브 안에서 운영합니다.
- 이미 오늘 날짜의 active 미션이 있으면 템플릿 적용 버튼으로 중복 생성하지 않습니다.
- 오늘의 미션 게시 기록이 있으면 같은 날짜 중복 게시는 하지 않습니다.
- `TODAY_MISSION_CHANNEL_ID`가 비어 있거나 봇이 메시지를 보낼 수 없으면 운영자에게만 오류가 보입니다.

## 8. 기본 템플릿 목록

예시 파일에는 아래 템플릿이 포함되어 있습니다.

- 월요일 가벼운 체크인
- 화요일 오늘의 사진 기록
- 수요일 짧은 대화 남기기
- 목요일 가벼운 회고
- 금요일 주간 정리
- 5,000보 걷기
- 나이키 런 1km 인증하기
- 오늘의 사진 기록
- 오늘의 회고 남기기
- 게릴라 특별 미션 예시

## 9. 운영자 QA 체크리스트

- [ ] `/운영현황`의 `미션 관리 허브`에서 템플릿 목록이 보입니다.
- [ ] 요일별 추천과 오늘의 추천이 보입니다.
- [ ] 템플릿 선택 후 미리보기 문구가 바뀝니다.
- [ ] 템플릿 적용 후 오늘 날짜의 active 미션이 생성됩니다.
- [ ] 이미 오늘 날짜의 active 미션이 있으면 새 미션이 중복 생성되지 않습니다.
- [ ] 생성된 미션은 `title`, `description`, `rewardPoints`, `requiresSubmission`, `status`, `activeDate`를 가지고 있습니다.
- [ ] `공지 미리보기`에 미션 제목, 설명, 지급 포인트, 인증 방법, #오늘의-미션 채널 안내가 보입니다.
- [ ] `오늘의 미션 게시` 후 #오늘의-미션 채널에 참여자용 안내가 올라갑니다.
- [ ] 같은 날짜에 다시 게시하려고 하면 중복 게시가 차단됩니다.
- [ ] 참여자 `/미션` 또는 `/인증` 제출 흐름이 기존처럼 pending 제출을 만듭니다.
- [ ] 승인/반려, 중복 지급 차단, Google Sheets append 흐름이 기존처럼 동작합니다.
- [ ] 자동 게시가 되지 않으므로 운영자가 필요한 채널에 직접 공지했습니다.
