# 웹게임 실환경 QA 체크리스트 (2026-07-13 비주얼 트랙 머지 이후)

PR #77·#80과 2026-07-13 머지분(#87 매치3 SVG 타일 · #88 idle 원화 · #91 덱 고도화 · #92 idle 리디자인)의 **실환경 확인 대기 항목**을 한 번에 처리하는 체크리스트입니다. 코드·자동 검증은 전부 끝난 상태이며, 여기 항목은 Railway·Discord 실계정·실기기에서만 확인할 수 있는 것들입니다.

- 표기 원칙: 통과하면 날짜를, 실패하면 증상을 "기록" 칸에 적습니다. 실패 항목은 이 문서에 남긴 채 이슈로 승격합니다.
- 이번 머지 4건은 전부 표시·입력 전용이라 `npm run deploy` 불필요, 슬래시 명령 변화 없음. **Railway 재배포(최신 main 반영)만 선행 조건**입니다.

## 1. `/게임지급` 실계정 리허설 (PR #77)

전제: 이번 주(또는 지난 주)에 연결 계정의 웹게임 점수 제출이 1건 이상 존재. 없으면 운영자 계정으로 `/게임연결` 후 아무 게임이나 1판 제출해 데이터를 만든다.

| # | 확인 | 방법 | 기대 결과 | 기록 |
| --- | --- | --- | --- | --- |
| 1-1 | 미리보기 | `/게임지급 주차:이번 주` | 지급 대상·금액 미리보기가 뜨고 **아직 지급되지 않음** | |
| 1-2 | 승인 지급 | 미리보기의 승인 버튼 | 지급 완료 응답 + `/포인트`로 대상 잔액 증가 확인 | |
| 1-3 | 중복 방지(멱등) | 같은 주차로 `/게임지급` 재실행 → 승인 | 이미 지급된 항목은 제외/차단되고 이중 지급 없음 | |
| 1-4 | 이력 | `/운영현황` 포인트 로그 | `weekKey:gameId:kind` 형태 relatedId로 지급 기록 확인 | |

## 2. 운영 콘솔 Phase 2 — 웹게임 판정·지급 (PR #80)

주의(과거 QA 교훈): `/admin`을 **자격증명 포함 URL로 열면 페이지 fetch가 전부 차단**됩니다 — 일반 URL + Basic Auth 입력으로 접속하세요. 쓰기 기능은 `ADMIN_WRITE_ENABLED=true`일 때만 — QA 후 원복 여부를 반드시 기록.

| # | 확인 | 방법 | 기대 결과 | 기록 |
| --- | --- | --- | --- | --- |
| 2-1 | 웹게임 섹션 표시 | `/admin` → 웹게임 운영 섹션 | 주간 요약·판정(verified/mismatch/missing) 표시, example 레코드 미노출 | |
| 2-2 | 리플레이 판정 값 | 정직 플레이 1판 제출 후 새로고침 | 해당 기록 verified | |
| 2-3 | 지급 흐름(쓰기 on일 때만) | 콘솔에서 지급 처리 | 감사 로그 남고 Discord `/포인트`와 잔액 일치 | |
| 2-4 | 쓰기 원복 | QA 종료 후 | `ADMIN_WRITE_ENABLED` 원래 값 확인 (기본 off) | |
