# 던전월드 브라우저 미니게임: 검은 종 생존전

`검은 종 생존전`은 기존 `/던전월드` 텍스트 미니게임의 세계관을 바탕으로 만든 브라우저용 2D 실시간 로그라이크 생존전입니다. 플레이어의 중심 목표는 검은탑의 마지막 문으로 향하는 것이고, 검은 종은 탑에서 울리는 저주와 보스 패턴의 신호로 쓰입니다. Discord 버튼형 게임이 아니라 `public/dungeonworld-survivors/` 아래의 정적 HTML/CSS/JS 파일로 동작합니다.

## 운영 원칙

- Discord 계정 연동이 없습니다.
- 포인트 지급, 포인트 차감, 베팅, 랭킹 저장이 없습니다.
- 기존 버튼형 미니게임의 하루 보상 상한과 중복 지급 정책은 변경하지 않습니다.
- `.env` 수정이나 `npm run deploy`가 필요하지 않습니다.
- 결과는 브라우저 화면 안에서만 끝납니다. 운영 데이터 JSON에도 저장하지 않습니다.

## 플레이 내용

- 플레이어는 방향키 또는 WASD로 이동합니다.
- 시작 시 전사, 사제, 도적, 드루이드, 마법사, 레인저 중 하나를 고릅니다.
- 기본 URL은 30분 정식 런으로 시작합니다. 기존 QA용 4분 데모 흐름은 `?mode=demo` 또는 로컬 `?qa=1`로 유지하며, `?mode=quick`을 붙이면 10분 퀵 런 구조로 시작합니다.
- 각 직업은 시작 능력치, 기본 공격, 생존 방식, 레벨업 선택지가 다릅니다.
- 기본 공격과 플레이북 장비는 자동으로 발동합니다.
- 월드는 960x540 단일 화면보다 큰 2400x1600 지도이며, 카메라가 플레이어를 따라가고 가장자리에서는 빈 공간이 보이지 않도록 고정됩니다.
- 지도에는 여관 쪽 시작 지점, 검은탑의 마지막 문으로 이어지는 길, 폐허, 숲, 물그릇, 검은탑 실루엣, 안개와 비네트가 캔버스 절차형 그림으로 표시됩니다.
- 적 웨이브는 `정찰 웨이브`, `뿌리 매복`, `물그릇 압박`, `숲의 추격`, `마지막 문` 순서로 바뀝니다.
- 30분 정식 런은 `0~3분`, `3~6분`, `6~9분`, `9~12분`, `12~15분`, `15~20분`, `20~25분`, `25~29분`, `29~30분` 구간으로 나뉩니다. 구간이 길어질수록 미믹, 신도, 늑대, 빈 갑옷, 검은탑 저주와 검은 종 위험 현상이 더 촘촘히 섞입니다.
- 고블린은 좌우로 흔들며 접근하고, 슬라임은 느리게 뭉쳐 밀고, 빈 갑옷은 버티다가 빨라지고, 그림자 늑대는 짧게 돌진합니다. 중후반에는 `물그릇 미믹`이 멈칫하다가 부채꼴 이빨 공격을 하고, `검은 종 신도`가 멀리서 원형 종말 기도를 예고합니다.
- 적은 접촉 즉시 피해만 주지 않고, 각자 다른 공격 범위와 짧은 예고 표시를 만든 뒤 피해를 줍니다. 예고 범위 밖으로 빠져나가면 해당 공격은 빗나갑니다.
- 웨이브별 위험 구역이 생깁니다. 뿌리 매듭은 이동을 늦추고 긴장을 올리며, 물그릇 웅덩이와 미믹 이빨은 중앙 압박을 만들고, 늑대 돌진로와 가시 십자로는 선형 예고를 보고 피해야 합니다. 마지막 문에서는 탑의 눈길과 검은 종파가 겹쳐 보스 위치를 계속 의식하게 만듭니다. 이때 검은 종은 목적지가 아니라 탑의 저주가 울리는 현상입니다.
- 경험치 보석을 모으면 레벨업하며, 아직 최대 레벨에 닿지 않은 업그레이드 3개 중 하나를 고릅니다. 선택지는 희귀도, 태그, 직업 적합도, 시너지 힌트를 함께 보여줍니다.
- 각 레벨업 선택지는 `현재 빌드`, `방향 전환`, `안정 보정` 중 어떤 역할로 제안됐는지와 짧은 추천 사유를 함께 보여줍니다. 카드에는 무기/패시브/강화 유형, `현재 Lv → 다음 Lv`, 이번 선택 효과, 짧은 추천 이유, 빌드 방향, 진화 상태가 분리되어 표시됩니다. 진화 재료, 진화 진행, 선택 후 진화 가능, 진화 가능 상태는 서로 다른 문구와 강조로 읽혀야 합니다. 최대 레벨에 도달한 업그레이드는 다시 나오지 않습니다.
- 내부 런 상태는 `inventory.weapons`, `inventory.passives`, `inventory.evolvedWeapons`로 보유 무기와 패시브를 나눠 기록합니다. 각 플레이북의 기본 공격은 시작 무기로 취급되며, 무기는 기본 최대 Lv.8, 패시브는 기본 최대 Lv.5를 기준으로 합니다.
- 무기 진화의 1차 규칙은 `무기 Lv.8 + 지정 패시브 보유 + 엘리트 상자 획득`입니다. 조건을 만족한 상태에서 상자를 열면 일반 강화보다 진화가 먼저 적용됩니다.
- 1차 진화 정의는 `철의 베기 → 방패선의 회전검`, `숨은 칼 → 그림자 칼비`, `축성의 빛 → 라메의 태양환`, `가시뿌리 → 고대 뿌리 감옥`, `마력탄 → 검은 서고의 유성`, `검은 화살 → 파수꾼 사냥매`입니다.
- 30분 정식 런에서는 5분 단위(`300, 600, 900, 1200, 1500초`)로 엘리트가 등장합니다. 엘리트를 쓰러뜨리면 캔버스에 상자가 남고, 플레이어가 상자에 닿으면 보상 모달이 열립니다. 진화 조건을 만족한 무기가 있으면 진화를 먼저 지급하고, 없으면 보유 무기/패시브 또는 업그레이드를 강화합니다. 진화 상자 보상은 일반 강화와 다른 `진화 획득` 헤더, 전후 비교, 진화 효과 문구를 보여줍니다.
- 같은 태그의 업그레이드를 모으면 `방패선`, `칼날 박자`, `뿌리 고리`, `검은 종 합창`, `기도 닻`, `추적 표식`, `비전 결계`, `판정의 틈` 같은 빌드 시너지가 열립니다. 각 선택 카드에는 희귀도와 태그뿐 아니라 “이 선택이 어떤 빌드를 만드는지”를 한 줄로 보여줍니다.
- 시작 직후부터 사이드 패널에 한 런 안에서만 평가되는 `런 목표`가 표시됩니다. 목표는 보스 전 레벨, 특정 태그 완성, 위험 구역 피해 억제, 특정 웨이브 처치, 보스 패턴 회피, 보스 처치 시간처럼 저장 없이 현재 런 기록만 사용합니다.
- 4분 데모에서는 약 3분 18초 뒤 검은탑의 마지막 문에서 `검은 종 파수꾼`이 등장합니다. 30분 정식 런에서는 29분 이후 마지막 문 구간에서 파수꾼이 등장합니다. 파수꾼을 쓰러뜨리면 성공, 체력이 0이 되면 실패입니다. 파수꾼은 마지막 문을 지키는 보스이며, 체력 구간에 따라 원형 종파, 직선 탑 그림자, 소환 압박, 십자형 종압을 번갈아 사용합니다.
- 결과 화면은 자동 빌드명과 평가, 생존 시간, 처치 수, 레벨, 플레이북, 런 목표 달성/실패/아까운 점, 직업별 보스전 기여, 선택한 업그레이드, 빌드 태그, 발동한 시너지를 요약합니다. 이 기록은 저장되지 않고 포인트 지급도 없습니다.

## 직업별 감각

| 직업 | 기본 공격 | 생존 방식 | 성장 방향 |
| --- | --- | --- | --- |
| 전사 | 가까운 적을 호로 베는 `철의 베기` | 높은 체력, 방어, 긴장 저항 | 방패 밀어붙이기, 철의 맹세, 방패 전진 |
| 사제 | 가까운 적을 태우는 `축성의 빛` | 주기적 회복, 판정 실패 완화 | 치유 기도문, 성역 원, 종소리 사면 |
| 도적 | 빠른 투사체와 부채꼴 `숨은 칼` | 높은 이동 속도, 회피, 자석 범위 | 그림자 걸음, 뒤찌르기 박자, 연막 주머니 |
| 드루이드 | 적을 늦추는 `가시뿌리` | 긴장에 비례한 기동, 잎 고리 | 짐승의 형상, 뿌리 미로, 달빛 가죽 |
| 마법사 | 관통하는 `마력탄` | 비전 보호막, 낮은 체력 | 검은 서고, 문양 축전, 갈라진 마력탄 |
| 레인저 | 긴 사거리의 `검은 화살` | 동료 매의 주기적 급강하 | 동료 매의 급강하, 매의 표식, 올가미 화살 |

각 직업은 선택 카드, 플레이어 실루엣, HUD 강조색, 기본 공격 형태가 다릅니다. 전사는 넓은 어깨와 방패, 사제는 성역 후광과 십자광, 도적은 낮은 몸과 단검 잔상, 드루이드는 뿌리 망토와 갈라진 땅, 마법사는 얇은 각진 룬 몸체와 보호막, 레인저는 활/망토/매 표식과 긴 화살 궤적을 사용합니다.

직업 스프라이트는 `public/dungeonworld-survivors/assets/classes/<class>.png` 아래의 64x64 투명 PNG를 사용합니다. 브라우저 게임은 시작 시 직업 스프라이트를 한 번 로드하고, 파일이 없거나 로드에 실패하면 기존 절차형 플레이어 렌더로 폴백합니다.

적 스프라이트는 `public/dungeonworld-survivors/assets/enemies/<enemy>.png` 아래의 투명 PNG를 사용합니다. 고블린, 슬라임, 빈 갑옷은 48x48, 늑대는 64x40, 미믹과 신도는 56x56, 파수꾼 보스는 `warden.png` 128x128입니다. 스프라이트가 없거나 로드에 실패하면 기존 절차형 적 렌더로 폴백하므로 운영 중 일부 에셋 누락이 게임 진행을 막지 않습니다.

적도 색보다 형태를 먼저 읽도록 절차형 캔버스 실루엣을 씁니다. 고블린은 작은 귀와 창, 슬라임은 눌린 물방울 몸체, 빈 갑옷은 사각 갑주와 비어 있는 투구, 그림자 늑대는 낮고 긴 몸과 돌진 잔상, 물그릇 미믹은 마름모 상자 입과 이빨, 검은 종 신도는 후드와 종 문양, 검은 종 파수꾼은 균열이 생기는 종탑 문지기 형상으로 구분합니다.

## 디자인 레퍼런스

- 디자인 보드 HTML은 `docs/design/` 아래에 보관하며 실제 게임 런타임에서 로드하지 않습니다.
- 캐릭터/몬스터/배경 아트 보드는 스프라이트 제작 기준입니다.
- 전투/보스 합본은 실제 화면에서 스프라이트와 엔진 레이어가 겹치는 기준을 확인하기 위한 프리뷰입니다.
- XP, 공격 전조, 위험선, HUD, 보스 체력바는 이미지화하지 않고 기존 엔진 렌더를 유지합니다.

보스전에서는 조작을 늘리지 않고 기존 이동, 자동 공격, 전조 회피 안에서 직업별 보정이 붙습니다. 전사는 파수꾼 가까이에 머물면 긴장과 피해 압박을 줄이고 근접 피해가 늘어납니다. 도적은 보스 패턴을 피한 직후 짧은 가속과 폭딜 창을 얻습니다. 사제는 보스 피해 뒤 치유 기도가 체력과 긴장을 일부 되돌립니다. 드루이드는 보스 패턴 뒤 뿌리 둔화와 이동 보상을 얻습니다. 마법사는 보호막으로 보스 피해를 받아내면 잠깐 주문 피해가 강화됩니다. 레인저는 거리를 유지한 표식 화살로 보스 피해를 올립니다.

## 화면 디자인

- 전체 UI는 검은탑으로 향하는 낡은 룰북/캐릭터 시트 느낌을 기준으로 합니다.
- 색상은 먹색 배경, 숯색 폐허, 낡은 양피지 표면, 녹슨 철 규칙선, 어두운 숲 녹색 액션, 황동 보상, 낮은 채도의 보라 저주를 사용합니다. 네온 웹 HUD처럼 빛나는 효과는 XP, 진화, 보스 경고 같은 정보성 순간에만 제한하고, 기본 화면은 선, 표면, 실루엣으로 읽히게 합니다.
- 제목과 카드 제목은 고딕풍 명조 계열 스택을 우선 사용하고, 본문은 한글 가독성이 높은 산세리프 스택을 사용합니다.
- 패널과 모달에는 얇은 규칙선, 톤 차이, 미세한 필름 그레인 오버레이를 적용합니다.
- 핵심 상태는 캔버스 가까이 있는 게임 HUD로 표시하고, 캐릭터 시트와 현재 장비는 보조 패널로 둡니다.
- 공격은 trail, impact mark, hit flash, 짧은 화면 흔들림을 사용하되 적과 경험치 보석을 가리지 않는 투명도로 유지합니다.
- 위험 예고는 네온 장판이 아니라 낮은 투명도의 피빛 의식선, 균열, 부채꼴, 원형 종파로 먼저 그려지고, 피해 판정은 예고가 끝난 뒤 일어납니다.
- 1차 전투 가독성 개선에서는 플레이어 위치 원/무적 보호막, 엘리트 위협 고리, 보스 상단 경고바, 위험 전조 단계별 틱, 적 사망 파편/연기, impact spark, 청록 XP 보석의 흡수 궤적, 레벨업 충격파를 사용합니다. 배경 장식은 낮은 채도와 낮은 대비로 유지하고, 붉은색/보라색/주황색 고대비 선은 실제 위험 전조와 강적 경고에 우선 배정합니다.
- 레벨업 카드는 룰북 전리품 카드처럼 추천 역할, 추천 사유, 희귀도, 룬/인장 배지, 직업 적합도, 시너지 힌트를 나눠 보여줍니다. 결과 모달은 `빌드명/평가 → 런 목표 → 보스전 기여 → 선택 업그레이드 → 시너지` 흐름의 빌드 요약 화면으로 사용합니다.
- `localhost` 또는 `127.0.0.1`에서 `?qa=1`을 붙이면 캔버스 오른쪽 위에 로컬 전용 밸런스 패널이 보입니다. 생존 시간, 처치 수, 레벨/XP, 현재 웨이브, 활성 적/위험 구역 수, 보스 상태/페이즈, 최근 선택 업그레이드, 추천 카드 구성, 런 목표 진행도, 마지막 문 보스전 기여 계측을 확인할 수 있습니다.

- 전사, 도적, 사제, 드루이드, 마법사, 레인저가 색상만이 아니라 방패/단검/후광/뿌리 망토/룬 몸체/활과 매 표식 형태로 구분되는지 확인합니다.
- 고블린, 슬라임, 빈 갑옷, 그림자 늑대, 물그릇 미믹, 검은 종 신도, 검은 종 파수꾼이 귀/창, 눌린 물방울, 빈 투구, 낮은 늑대 몸, 이빨 상자, 후드 종문양, 균열 종탑 형태로 구분되는지 확인합니다.
- 적 공격 전조가 보인 뒤 피해가 들어오는지 확인합니다. 예고 범위 밖으로 빠져나갔을 때는 피해를 받지 않아야 합니다.
- 웨이브 위험 구역이 보이는지 확인합니다. 뿌리 매듭, 물그릇 웅덩이, 늑대 돌진로, 검은 종파는 적과 경험치 보석을 가리지 않아야 합니다.

## 로컬 실행

파일만 열어도 동작하지만, 브라우저 QA는 로컬 정적 서버로 확인하는 것을 권장합니다.

```bash
python3 -m http.server 4173 --directory public
```

브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:4173/dungeonworld-survivors/
http://127.0.0.1:4173/dungeonworld-survivors/?mode=demo
http://127.0.0.1:4173/dungeonworld-survivors/?mode=standard
http://127.0.0.1:4173/dungeonworld-survivors/?mode=quick
```

보스 흐름과 밸런스 표시를 브라우저에서 빠르게 확인해야 할 때는 로컬 주소에 `?qa=1`을 붙입니다. 실행 중 `Shift+B`로 마지막 문 보스 등장, `Shift+N`으로 보스 처치 결과, `Shift+L`로 레벨업 카드, `Shift+C`로 일반 상자 보상, `Shift+E`로 진화 상자 보상을 확인할 수 있습니다. 이 패널과 단축키는 `127.0.0.1` 또는 `localhost`에서 `?qa=1`이 붙은 경우에만 동작합니다.

봇 프로세스의 HTTP 서버가 켜져 있는 환경에서는 `/game/dungeonworld-survivors` 경로로도 정적 파일을 서빙할 수 있습니다. 이 경로는 대시보드 API와 달리 Basic Auth를 요구하지 않습니다.
