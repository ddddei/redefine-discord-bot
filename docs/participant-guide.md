# 프로젝트 리디파인 참여자 가이드

프로젝트 리디파인 디스코드에 처음 오신 분을 위한 안내서입니다. 처음부터 전부 읽거나 외울 필요는 없어요. 막히는 부분이 생겼을 때 해당 부분만 찾아봐도 충분합니다.

## 1. 디스코드가 뭐예요?

디스코드(Discord)는 카카오톡처럼 대화를 나누는 채팅 앱이에요. 다른 점이 하나 있다면, 대화 공간이 주제별 "채널"로 나뉘어 있다는 것입니다. 공지는 공지 채널에서, 미션은 미션 채널에서 확인하는 식이라 필요한 내용만 골라 볼 수 있어요.

리디파인 디스코드는 공지, 일정, 질문, 미션, 포인트, 상점을 한곳에서 확인하는 우리 프로그램의 온라인 공간입니다.

## 2. 앱 설치와 계정 만들기

### 휴대폰에서 (권장)

1. 앱스토어(아이폰) 또는 플레이스토어(안드로이드)에서 **Discord**를 검색해 설치합니다.
2. 앱을 열고 **회원가입**을 누릅니다. 전화번호 또는 이메일로 가입할 수 있어요.
3. 이름은 본명이 아니어도 괜찮습니다. 편한 이름으로 정해 주세요.
4. 생년월일 입력과 인증 절차를 마치면 가입 완료입니다.

### 컴퓨터에서

1. discord.com 에 접속해 **Windows용/Mac용 다운로드**를 누르거나, 브라우저에서 바로 사용할 수도 있어요.
2. 가입 방법은 휴대폰과 같습니다.

이미 디스코드 계정이 있다면 새로 만들지 않고 기존 계정을 그대로 쓰면 됩니다.

## 3. 리디파인 서버에 들어오기

1. 운영진이 문자나 카카오톡으로 보내드린 **초대 링크**를 눌러 주세요.
2. "프로젝트 리디파인에 오신 것을 환영합니다" 화면이 나오면 **초대 수락**을 누릅니다.
3. 오리엔테이션 현장에서는 화면의 QR 코드를 휴대폰 카메라로 찍어도 같은 화면으로 이동해요.
4. 잘 안 되면 그 자리에서 운영진에게 편하게 말씀해 주세요. 같이 해결하면 됩니다.

## 4. 들어와서 처음 할 3가지

서버에 들어오면 이 세 가지만 하면 준비 끝입니다.

1. **참여동의 확인** — `#참여동의-확인` 채널의 안내를 읽고, 메시지 아래 이모지 중 하나를 눌러 주세요. 인증이 완료되면 다른 채널들이 열립니다.
2. **이름표 고르기** — `#이름표-색상-고르기` 채널에서 나를 표시할 색상을 골라 주세요. 바로 정하기 어렵다면 나중에 해도 괜찮아요.
3. **`/안내` 실행** — 아무 채팅 채널에서 `/안내`를 입력하고 `🌱 처음 왔다면 여기부터` 버튼을 눌러 보세요. 나에게만 보이는 시작 가이드가 열립니다.

여기까지 하면 오늘 할 일은 다 한 거예요. 나머지는 천천히 둘러보면 됩니다.

## 5. 채널 간단 안내

| 채널 | 용도 |
| --- | --- |
| `#공지_관리자-공지` | 중요한 전체 공지. 가끔 확인해 주세요 |
| `#프로젝트공지_일정및안내` | 프로그램 날짜, 시간, 장소 안내 |
| `#환영-인사와-규칙` | 기본 규칙과 분위기 소개 |
| `#자유채팅방` | 일상 이야기. 보기만 해도 괜찮아요 |
| `#익명고민채널` | 이름을 드러내기 부담스러운 고민이나 질문 |
| `#오늘의-미션` | 오늘의 미션 확인과 인증 업로드 |
| `#매일출석체크` | 출석/체크인 관련 공간 |
| `#포인트-상점` | 포인트로 교환 가능한 항목 안내 |
| `#포인트로게임하기` | 미니게임 공간 (선택 활동) |
| `#랭킹확인` | 게임 기록 확인 (재미 요소) |

채널이 적게 보여도 문제가 아니에요. 처음에는 필요한 채널만 열려 있고, 각자의 속도에 맞춰 공간이 열립니다. 헷갈릴 때는 `/채널안내`를 입력하면 채널 안내를 다시 볼 수 있어요.

## 6. 봇 사용법 — 이것만 기억하세요

`/`(슬래시)를 입력하면 사용할 수 있는 명령어 목록이 떠요. 처음에는 이 다섯 개면 충분합니다.

| 명령어 | 하는 일 |
| --- | --- |
| `/안내` | 전체 사용법을 메뉴로 확인 (헷갈리면 언제든 이것부터) |
| `/체크인` | 오늘의 참여 기록 남기기 (하루 1회, 포인트 지급) |
| `/미션` | 오늘 참여할 수 있는 미션 확인 |
| `/포인트` | 내 리디파인 포인트 확인 (나만 볼 수 있어요) |
| `/상점` | 포인트로 교환 가능한 항목 보기 |

봇의 응답은 대부분 **나에게만 보이는 메시지**라서, 다른 사람에게 내 포인트나 활동이 공개되지 않아요.

## 7. 미션 참여와 인증

미션은 꼭 해야 하는 과제가 아니라 **가능한 날에, 가능한 만큼** 참여하는 선택 활동이에요.

1. `/미션`으로 오늘 참여 가능한 미션을 확인합니다.
2. `#오늘의-미션` 채널에 글, 사진, 영상 중 편한 방식으로 인증을 올립니다.
3. 올리면 자동으로 접수되고, 운영진이 확인한 뒤 리디파인 포인트가 지급됩니다.
4. 승인 결과는 봇이 DM으로 알려드리고, `/포인트`에서도 확인할 수 있어요.

사진을 올릴 때 얼굴, 주소, 연락처처럼 민감한 정보는 가려도 괜찮습니다.

## 8. 리디파인 포인트와 상점

리디파인 포인트는 경쟁이나 순위를 위한 점수가 아니라, 참여 흐름을 기록하는 작은 보상이에요. 체크인, 미션 인증 등으로 모을 수 있습니다.

모은 포인트는 `/상점`에서 확인하고 `/교환`으로 신청할 수 있어요. 예를 들어 **청년동 포인트 전환** 같은 항목이 있습니다.

- 신청 전 확인 화면에서 필요한 포인트와 신청 후 잔액을 보여드려요.
- 신청을 완료하면 포인트가 차감되고, 운영진이 확인 후 처리해 드립니다.
- 단순 변심에 따른 취소나 환불은 어려울 수 있으니 신청 전에 한 번만 더 확인해 주세요.

## 9. 봇과 1:1 대화 연습 (DM)

공개 채널에 글을 쓰는 게 아직 부담스럽다면, **리디파인 가이드 봇에게 DM(개인 메시지)으로 말을 걸어 보세요.** 봇이 대화 연습 상대가 되어드려요.

- 왼쪽 메뉴에서 **리디파인 가이드 봇**을 찾아 DM을 보내면 시작됩니다. "안녕"처럼 가벼운 한마디면 충분해요.
- 사람들과 대화하기 전에 짧게 연습하는 공간이에요. 첫인사, 말 걸기, 짧은 답장 같은 걸 같이 맞춰볼 수 있어요.
- `연습 메뉴`라고 보내면 연습 주제를, `새로 시작`이라고 보내면 대화를 새로 시작할 수 있어요.

미리 알아두면 좋은 것:

- 이 대화는 참가자 보호와 운영 지원을 위해 **기록되며 운영진이 확인할 수 있어요.** 기록은 90일 뒤 자동 정리되고, 원하면 언제든 삭제를 요청할 수 있습니다.
- 봇과의 대화는 AI와의 연습이에요. **상담이나 진단, 긴급한 도움을 대신하지 않습니다.** 힘들거나 급한 일은 운영진에게 직접 말씀해 주세요.
- 하루에 연습할 수 있는 횟수에는 넉넉한 상한이 있어요. 다 쓰면 내일 다시 이어서 연습하면 됩니다.

## 10. 궁금한 점이 있을 때

- 가벼운 질문: 아무 채널에서 `/질문` 입력 후 궁금한 내용 작성
- 이름을 밝히기 부담스러운 이야기: `#익명고민채널`
- 개인적인 문의나 어려운 일: 운영진에게 DM 또는 문의 채널

봇이 답하기 어려운 질문은 운영진이 확인하고 답변드려요. 어떤 질문이든 괜찮습니다.

## 11. 마지막으로

처음부터 완벽하게 참여하지 않아도 됩니다. 읽기만 해도, 이모지 반응만 눌러도 참여예요. 각자의 속도로 함께 가면 됩니다.
