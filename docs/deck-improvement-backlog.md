# 간식 수호대(덱빌딩) 고도화 백로그

`public/deck/`의 고도화 후보 목록입니다. v1 계획서([deck-web-game-plan.md](deck-web-game-plan.md))가 의도적으로 뺀 것들이 1차 후보입니다. 착수 시 항목별 계획서를 만듭니다. 공통 원칙: `engine.js` 시드 결정성 유지(이어하기 RNG 재현·오늘의 도전·리플레이 검증 v2의 전제), 점수 공식 변경 시 `GAME_DEFINITIONS.deck.maxScore` 재산정.

## 0. 현재 상태

선형 11칸(일반6+정예2+휴식2+보스1)·적 1명·의도 예고·상태 3종·카드 18종+시작덱 3종·이어하기. 적 9종 회화 원화. 주간/일일 랭킹·응원 연동 완료.

## 1. 백로그 (우선순위순)

### D1 — 카드 풀 확장 + 유물 [효과 큼 / 중]

- 카드 +10~15종(태그 시너지 축 추가), 유물(런 전체 지속 효과) 6~10종 — 휴식 칸 선택지·정예 보상으로 지급. 반복 플레이의 빌드 다양성이 핵심 부족분.
- 유물은 상태 스키마 확장(저장 버전 필드 올리고 구버전 세이브 관용 처리).

### D2 — 갈림길 맵 [효과 큼 / 중~대]

- 선형 11칸 → 분기 선택(전투/정예/휴식/이벤트 중 택1). "선택의 게임"이라는 장르 핵심. 시드 결정적 맵 생성.
- D1 이후 권장(선택지가 있어야 갈림길이 의미 있음).

### D3 — 이벤트 칸 [중 / 중]

- 텍스트 선택지 이벤트(위험/보상 트레이드) 8~12종 — 던전월드 텍스트 게임의 작법 재사용 가능. 스토리북 톤과 궁합 좋음.

### D4 — 오늘의 도전 변형 [중 / 소]

- 고정 시작덱 지정·수정 규칙(예: 비용 +1 저주 카드 포함) — dayKey 결정적. 일일 랭킹의 "같은 조건" 재미 강화.

### D5 — 다중 적 전투 [하 / 대]

- 전투당 적 2~3명(대상 선택 UI 필요 — 모바일 탭 타겟 재설계 동반). 볼륨 크고 밸런스 전면 재작업. D1~D3 이후.

### D6 — 메타 해금 [하 / 중]

- 통산 기록 기반 카드/시작덱 해금(localStorage). 생존전 S3와 같은 패턴 — 같이 설계하면 좋음.

## 2. 하지 않기로 확인한 것

- 카드 뽑기/가챠식 수집 — 보상 설계가 참여자 맥락(사행성 회피)과 충돌
- PvP·비동기 덱 대전 — 밸런스·부정 방지 볼륨이 현 단계에 과함
