# 검은 종 생존전 디자인 방향서

이 문서는 `public/dungeonworld-survivors/` 웹게임의 후속 디자인 개선 작업을 위한 기준 문서입니다.

이번 문서는 구현 지시서가 아니라 디자인 판단 기준입니다. 실제 게임 코드, CSS, JavaScript 수정은 별도 작업에서 다룹니다.

## 1. 현재 문제 요약

현재 1차 기능 구현은 플레이 가능한 형태를 갖췄지만, 뱀서라이크 장르에서 중요한 전투 가독성, 타격감, 보상 기대감이 아직 약합니다.

### 1.1 캐릭터와 적이 아이콘처럼 보임

플레이어와 적이 게임 속 생명체라기보다 UI 아이콘처럼 느껴집니다.

후속 디자인에서는 캐릭터와 적이 최소한의 실루엣만으로도 역할과 위협도를 구분할 수 있어야 합니다. 플레이어는 조작 대상, 일반 적은 접근 위협, 엘리트와 보스는 즉시 경계해야 하는 대상으로 보여야 합니다.

### 1.2 공격 타격감이 약함

공격이 명중했는지, 적이 얼마나 피해를 받았는지, 적이 죽었는지에 대한 피드백이 약합니다.

후속 디자인에서는 피격, 처치, 경험치 획득, 레벨업, 상자 획득, 진화 발동이 각각 다른 감각으로 읽혀야 합니다.

### 1.3 위험 구역과 배경이 헷갈림

전투 배경의 분위기 요소와 실제 위험 전조가 시각적으로 섞일 수 있습니다.

후속 디자인에서는 배경은 세계관 분위기를 담당하고, 피해를 주는 장판이나 보스 패턴 전조는 명확한 색, 형태, 애니메이션으로 분리해야 합니다.

### 1.4 보스 존재감이 약함

보스가 일반 적의 큰 버전처럼 보이면 런의 목표와 긴장감이 약해집니다.

후속 디자인에서는 보스 등장 전 경고, 전용 체력바, 패턴명, 고유 실루엣으로 보스전을 일반 웨이브와 분리해야 합니다.

### 1.5 레벨업 카드가 텍스트 중심이라 직관성이 부족함

레벨업 선택지가 텍스트 설명에 의존하면 빠르게 판단하기 어렵습니다.

후속 디자인에서는 카드의 종류, 현재 레벨, 다음 레벨, 이번 선택의 효과, 진화 조건, 추천 이유가 한눈에 보여야 합니다.

### 1.6 결과 화면 이후 다시 플레이할 이유가 약함

런 종료 후 무엇을 얻었고 다음에는 무엇을 목표로 하면 좋을지 약합니다.

후속 디자인에서는 이번 런의 성과, 해금, 다음 목표, 영구 성장 가능성을 결과 화면에서 명확히 보여야 합니다. 단, localStorage 기반 메타 진행 구현은 별도 후속 작업으로 분리합니다.

## 2. 핵심 디자인 방향

검은 종 생존전은 다크 판타지 분위기의 뱀서라이크로 정리합니다.

분위기는 `Halls of Torment` 계열의 어둡고 거친 던전 판타지를 참고합니다. 화면은 황량한 돌바닥, 의식의 흔적, 오래된 종탑, 검은 종, 황동 장식, 보라색 기운 같은 소재로 무게감을 가질 수 있습니다.

UI와 장르 문법은 `Vampire Survivors`처럼 명확해야 합니다. 생존 시간, 체력, 레벨, 경험치, 무기, 패시브, 보스 체력바, 상자, 진화 가능 여부는 플레이어가 별도 설명 없이 이해할 수 있어야 합니다.

전투 가독성은 `Brotato`, `20 Minutes Till Dawn`처럼 명확해야 합니다. 배경이 어두워도 플레이어, 적, 투사체, 경험치, 위험 전조는 서로 섞이면 안 됩니다.

## 3. 전투 화면 디자인 원칙

### 3.1 배경은 분위기

배경은 세계관과 긴장을 만드는 역할입니다. 배경 디테일이 전투 판단을 방해하면 안 됩니다.

권장 방향:

- 낮은 대비의 석재 바닥, 균열, 의식 문양, 종탑 그림자를 사용합니다.
- 강한 채도와 밝은 외곽선은 위험 전조, XP, 보상, 공격 피드백에 우선 배정합니다.
- 배경 장식은 반복 패턴보다 진행 중인 의식이나 검은 종의 영향이 느껴지는 형태가 좋습니다.

### 3.2 플레이어, 적, XP, 위험 전조는 명확하게 분리

전투 판단에 필요한 요소는 색과 움직임의 역할을 고정합니다.

권장 구분:

- 플레이어: 밝은 중심부, 분명한 외곽선, 이동 방향이 읽히는 실루엣
- 일반 적: 어두운 몸체와 붉거나 보라색의 위협 포인트
- 엘리트: 일반 적보다 큰 실루엣, 별도 외곽선, 사망 시 상자 기대감
- XP: 전투 오브젝트와 다른 청록색 또는 푸른색 계열의 작은 보석
- 위험 전조: 붉은색, 주황색, 보라색 중 하나를 강하게 사용하되 배경 문양과 섞이지 않게 처리

### 3.3 실루엣만 봐도 역할이 보여야 함

플레이어와 적은 색을 제거해도 역할이 어느 정도 읽혀야 합니다.

권장 기준:

- 플레이어는 작은 망토, 무기, 빛나는 핵심부처럼 조작 대상을 나타내는 특징이 있어야 합니다.
- 일반 적은 접근 방향과 공격 방식이 형태로 드러나야 합니다.
- 원거리 적은 팔, 지팡이, 투사체 준비 자세처럼 일반 근접 적과 다른 실루엣을 가져야 합니다.
- 보스는 화면 크기, 자세, 장식, 중심 소재가 일반 적과 확실히 달라야 합니다.

## 4. 타격감 방향

타격감은 단일 이펙트가 아니라 여러 짧은 피드백의 조합으로 만듭니다.

후속 작업에서 우선 검토할 피드백:

- 적 피격 flash: 명중 순간 적이 짧게 밝아지거나 색이 반전됩니다.
- 적 사망 파편: 사망 시 작은 파편, 잔불, 어둠 조각이 흩어집니다.
- XP 흡수 궤적: XP가 플레이어에게 끌려올 때 곡선 궤적과 가속감을 줍니다.
- 레벨업 충격파: 레벨업 순간 플레이어 주변에 짧은 원형 파동을 표시합니다.
- 상자/진화 연출: 상자는 일반 드롭보다 더 무겁고 느리게 등장하며, 진화 가능 시 별도 색과 사운드 감각을 가정합니다.
- 보스 등장 경고: 화면 가장자리 경고, 짧은 정지감, 보스명, 전용 체력바로 진입감을 줍니다.

## 5. HUD 방향

HUD는 전투를 방해하지 않으면서 뱀서라이크의 핵심 정보를 항상 보여야 합니다.

필수 정보:

- 생존 시간
- 체력
- 레벨/XP
- 무기 슬롯
- 패시브 슬롯
- 진화 가능 표시
- 엘리트/보스 체력바

권장 배치:

- 생존 시간은 화면 상단 중앙에 둡니다.
- 체력과 레벨/XP는 플레이어 상태를 한눈에 볼 수 있는 상단 또는 하단 고정 영역에 둡니다.
- 무기 슬롯과 패시브 슬롯은 아이콘 중심으로 표시하고, 레벨은 작은 배지로 표시합니다.
- 진화 가능 상태는 관련 무기와 패시브 슬롯에 별도 표시를 붙입니다.
- 보스 체력바는 화면 상단에 넓게 배치하고, 보스명과 패턴명을 함께 보여줍니다.

## 6. 레벨업 카드 방향

레벨업 화면은 빠른 판단을 도와야 합니다. 텍스트 설명은 보조이고, 카드의 시각 구조가 먼저 의미를 전달해야 합니다.

카드에서 구분할 정보:

- 무기
- 패시브
- 강화
- 진화 재료
- 현재 레벨 → 다음 레벨
- 이번 선택 효과
- 진화 조건
- 추천 이유

권장 카드 구조:

- 상단: 카드 종류와 아이콘
- 중앙: 이름, 현재 레벨, 다음 레벨
- 본문: 이번 선택으로 바뀌는 수치나 효과
- 하단: 진화 조건 또는 추천 이유

추천 이유 예시:

- 현재 주무기와 조합 가능
- 생존력이 부족할 때 유리
- 보스전 화력 보강
- 진화 조건 충족에 필요

## 7. 상자/진화 연출 방향

상자는 엘리트 처치의 보상 기대감을 담당합니다.

기본 흐름:

1. 엘리트 처치 후 상자가 드롭됩니다.
2. 플레이어가 상자를 획득하면 보상 연출이 시작됩니다.
3. 진화 조건이 충족된 무기가 있으면 상자 보상에서 진화를 우선합니다.
4. 진화 전후 비교를 보여줍니다.
5. 진화 무기가 첫 발동할 때 짧은 전용 연출을 보여줍니다.

진화 연출에서 보여야 할 정보:

- 진화 전 무기
- 필요한 패시브 또는 재료
- 진화 후 무기명
- 핵심 효과 변화
- 첫 발동 시 전투 화면에서 체감되는 차이

## 8. 보스 디자인 방향

보스는 검은 종 생존전의 제목과 세계관을 가장 강하게 보여주는 장치입니다.

핵심 소재:

- 검은 종
- 종탑
- 문지기
- 의식
- 황동
- 보라 기운

보스 시각 기준:

- 일반 적과 확실히 다른 실루엣을 가집니다.
- 화면에 등장하기 전 경고가 먼저 나옵니다.
- 보스 전용 체력바가 표시됩니다.
- 현재 패턴명이 표시됩니다.
- 공격 전조는 배경 장식보다 높은 우선순위로 읽혀야 합니다.

보스 후보 방향:

- 검은 종의 문지기: 거대한 황동 종추나 사슬을 들고 접근하는 수호자
- 종탑 의식자: 보라 기운으로 장판과 원거리 패턴을 사용하는 사제형 보스
- 균열의 종: 몸체 자체가 검은 종이며, 울림으로 원형 충격파를 만드는 고정형 보스

## 9. 결과 화면과 메타 진행 방향

결과 화면은 실패 또는 성공을 알리는 화면에서 끝나면 안 됩니다. 다음 런을 시작할 이유를 만들어야 합니다.

결과 화면에서 보여야 할 정보:

- 이번 런에서 얻은 것
- 이번 런의 최고 생존 시간
- 처치 수
- 보스 또는 엘리트 처치 여부
- 새로 발견한 무기나 진화
- 다음 목표
- 해금 후보
- 영구 성장 항목

다음 목표 예시:

- 5분 생존
- 첫 엘리트 처치
- 첫 상자 획득
- 첫 진화 달성
- 검은 종 보스 조우
- 특정 무기 레벨 달성

메타 진행 원칙:

- localStorage 기반 메타 진행은 후속 작업으로 분리합니다.
- 메타 진행이 추가되더라도 Discord 포인트, 랭킹, 관리자 대시보드와 연결하지 않습니다.
- 첫 단계에서는 브라우저 로컬 플레이 경험 안에서만 해금과 성장감을 제공합니다.

## 10. 후속 디자인 작업 범위 기준

이 문서 이후 디자인 구현 작업은 다음 순서로 나누는 것이 좋습니다.

1. 전투 가독성 개선: 플레이어, 적, XP, 위험 전조의 시각 분리
2. 타격감 개선: 피격 flash, 사망 파편, XP 흡수, 레벨업 충격파
3. HUD 개선: 생존 시간, 체력, XP, 슬롯, 보스 체력바 정리
4. 레벨업 카드 개선: 종류, 레벨 변화, 진화 조건, 추천 이유 표시
5. 상자/진화 연출 개선: 엘리트 보상과 진화 우선 흐름
6. 보스 연출 개선: 등장 경고, 전용 체력바, 패턴명, 실루엣
7. 결과 화면 개선: 이번 런 성과와 다음 목표 표시
8. localStorage 메타 진행: 후속 별도 작업으로 검토

## 12. 디자인 구현 우선순위

디자인 구현은 한 번에 전체를 바꾸지 않고, 플레이어가 체감하는 문제 순서대로 진행한다.

1. 전투 가독성
   - 플레이어, 적, XP, 위험 전조, 배경을 분리한다.
   - 이 단계가 끝나기 전에는 장식적 리디자인을 우선하지 않는다.

2. 타격감
   - 피격 flash, 사망 파편, XP 흡수 궤적, 레벨업 충격파를 추가한다.
   - 공격이 맞았는지, 적이 죽었는지, 내가 성장했는지 즉시 보여야 한다.

3. HUD와 레벨업 카드
   - 무기/패시브/진화 가능 여부를 한눈에 보여준다.
   - 레벨업 카드는 텍스트 설명보다 선택 이유가 먼저 보여야 한다.

4. 보스와 상자/진화 연출
   - 보스 등장, 상자 획득, 진화 발동은 일반 전투와 다른 사건처럼 보여야 한다.

5. 결과 화면과 메타 진행 UX
   - 이번 런에서 얻은 것과 다음 목표를 보여준다.
   - localStorage 기반 메타 진행은 별도 기능 작업으로 분리한다.

## 13. 디자인 개선 완료 기준

디자인 개선 작업은 아래 기준을 만족해야 한다.

- 플레이어 위치를 1초 안에 찾을 수 있다.
- 일반 적, 엘리트, 보스가 실루엣으로 구분된다.
- XP 보석과 위험 전조가 서로 헷갈리지 않는다.
- 공격 명중, 적 처치, XP 흡수, 레벨업이 각각 다른 피드백으로 보인다.
- 레벨업 카드에서 무기/패시브/강화/진화 관련 선택지가 구분된다.
- 보스 등장 시 화면, HUD, 전조, 체력바가 일반 웨이브와 다르게 보인다.
- 결과 화면에서 이번 런의 성과와 다음 목표가 보인다.
- 디자인 개선 후에도 Discord 포인트, 랭킹, 계정 연동은 추가되지 않는다.

## 14. 피해야 할 디자인 방향

- 캐릭터와 적을 단순 기하학 아이콘처럼만 표현하지 않는다.
- 배경 장식에 위험 전조와 비슷한 강한 붉은색/보라색 패턴을 남발하지 않는다.
- 레벨업 카드를 긴 설명문 중심으로 만들지 않는다.
- 보스를 일반 적의 크기만 키운 형태로 만들지 않는다.
- HUD를 장식적으로만 만들고 무기/패시브/진화 상태를 숨기지 않는다.
- 타격감을 사운드에만 의존하지 않는다. 시각 피드백만으로도 명중과 처치가 읽혀야 한다.
- 다크 판타지 분위기를 이유로 모든 요소를 어둡게 만들지 않는다.
