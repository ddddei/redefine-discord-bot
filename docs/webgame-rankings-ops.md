# 웹게임 랭킹 운영 절차 (연동 v1)

`간식 맞추기`(match3), `간식 수호대`(deck), `간식 공방 키우기`(idle) 3종 웹게임에 Discord 계정 연결·서버 점수 기록·주간 랭킹 조회 기능이 추가됐습니다([webgame-discord-link-plan.md](webgame-discord-link-plan.md) 참고). 이 문서는 v1 운영 절차만 다룹니다.

## v1 범위와 원칙

- v1에서는 **포인트 자동 지급을 하지 않습니다.** 부정 방지가 완전히 검증되기 전까지 자동 지급은 위험하다고 판단해, 운영자가 랭킹을 보고 기존 포인트 명령으로 수동 지급하는 절차를 공식 루프로 둡니다.
- 실시간 멀티플레이는 범위 밖입니다. 랭킹은 "이번 주 최고 기록" 기준 비동기 경쟁입니다.
- `간식 공방 키우기`(idle)는 방치형 장르 특성상 랭킹 대상이 아닙니다. 주간 누적 생산량이 참여 기록으로만 서버에 남고, 랭킹 화면에는 노출되지 않습니다.

## 참여자 사용 흐름

1. Discord에서 `/게임연결`을 실행하면 6자리 코드가 DM으로 발급됩니다(DM이 막혀 있으면 에페메랄 메시지로 대체). 코드는 10분간 유효합니다.
2. 웹게임(매치3/덱빌딩 결과 화면, 방치형 기록 탭)의 계정 연결 섹션에 코드를 입력하면 연결됩니다.
3. 매치3/덱빌딩은 게임 종료 시, 방치형은 기록 탭 진입 시 점수가 서버로 자동 제출됩니다(참여자가 별도로 할 일은 없습니다).
4. Discord에서 `/게임랭킹 게임:<선택>`으로 이번 주 상위 10명을 확인할 수 있습니다. 웹게임 화면에서도 이번 주 랭킹과 내 순위를 확인할 수 있습니다.
5. 재연결(기기 변경 등)은 `/게임연결`을 다시 실행하면 됩니다. 이전 토큰은 자동으로 무효화됩니다.

## 운영자 주간 점검 절차

1. 매주 월요일(또는 정기 점검일), 운영자가 `/게임랭킹 게임:<match3|deck|idle>`로 지난 주 상위자를 확인합니다. `idle`은 랭킹 대상이 아니므로 참여 여부만 참고합니다.
2. 운영 정책에 따라 기존 `/포인트관리` 명령으로 수동 지급합니다.
   - 지급 기준 (2026-07-04 운영 결정):
     - 1위: `3,000P`
     - 2위: `2,000P`
     - 3위: `1,000P`
     - 참여자 전원(순위 무관, 해당 주 제출 기록 1건 이상): `500P`
   - 순위 보상과 참여 보상은 중복 지급합니다 (예: 1위는 3,000 + 500 = 3,500P).
3. 지급 사유에는 게임명과 주차(예: `2026-W27`)를 남겨 `/포인트로그`에서 추적할 수 있게 합니다. 예: "간식 맞추기 2026-W27 주간 랭킹 1위".
4. 대시보드(`/admin`, 활성화된 경우)에서 이상치로 플래그된 기록(`flagged: true`)이 있는지 확인합니다. 플래그된 기록은 랭킹 계산에서 자동 제외되지만, 필요하면 해당 참여자의 해당 주 지급을 보류하거나 직접 확인합니다.
5. 청년동 자판기 교환은 기존 `/상점` → `/교환` 흐름을 그대로 사용합니다. 이 흐름을 위해 신규로 개발한 부분은 없습니다.

## 부정 방지 v1 요약 (참고용)

완벽한 검증이 아니라 억지력 수준입니다. 자세한 구현은 `src/webgameApi.js`를 참고하세요.

| 항목 | 기준 |
| --- | --- |
| 게임별 점수 상한 | match3 50,000점, deck 11,060점(도달 스테이지×1000+잔여 HP 이론상 최대), idle 상한 없음에 가까운 넉넉한 값 |
| 빈도 제한 | 토큰당 분당 3회, 일 50회 초과 시 429 |
| 이상치 플래그 | 직전 주 최고 기록의 3배를 초과하면 `flagged: true`로 기록만 하고 랭킹에서는 제외 |
| 리플레이 검증 | v1에는 없음(v2 후보) |

## 확인이 필요한 상황

- 특정 참여자의 점수가 비정상적으로 높아 보이면 `flagged` 여부와 무관하게 운영진 판단으로 지급을 보류할 수 있습니다.
- `/게임연결` DM이 계속 실패하는 참여자는 서버 DM 수신 설정을 확인하도록 안내해 주세요(에페메랄 메시지로도 코드를 확인할 수 있습니다).
- 랭킹 데이터(`data/webgame-links.local.json`, `data/webgame-scores.local.json`)는 다른 local JSON과 마찬가지로 커밋하지 않습니다.
