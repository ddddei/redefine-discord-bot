# DM 대화 실계정 리허설 가이드

이 문서는 DM 기능을 실제 참여자에게 열기 전 운영자가 직접 확인할 항목입니다. 현재 저장소 작업에서는 실계정·Railway 검증을 수행하지 않았으므로 모든 항목의 초기 상태는 **운영자 확인 대기**입니다. 테스트 DM 원문, 사용자 ID, 실제 채널 ID는 GitHub 문서나 Issue에 복사하지 않습니다.

## 테스트 역할

| 역할 | 목적 | 준비 상태 |
| --- | --- | --- |
| 참여자 | 정상 대화·연습·제한 확인 | 운영자 확인 대기 |
| 비멤버 | 1회 안내 후 침묵 확인 | 운영자 확인 대기 |
| DM 차단 | 안내 전송 실패와 운영 로그 확인 | 운영자 확인 대기 |
| 운영자 | `/운영현황`·`/admin` 대조 | 운영자 확인 대기 |
| 안전 담당 운영자 | 안전 큐 확인·후속·종료 처리 | 운영자 확인 대기 |

## 첫 안내 이해도 질문

개인 식별 정보 없이 통과 여부와 개선이 필요한 문장만 남깁니다.

1. 누구와 대화한다고 이해했나요?
2. 기록을 누가 어떤 목적으로 볼 수 있다고 이해했나요?
3. 삭제를 원할 때 어떻게 해야 한다고 이해했나요?
4. 급하거나 안전이 걱정되는 상황에서 이 기능 대신 무엇을 해야 하나요?

| 참여자 구분 | 1 | 2 | 3 | 4 | 개선 문장 | 상태 |
| --- | --- | --- | --- | --- | --- | --- |
| 테스트 A | 미실행 | 미실행 | 미실행 | 미실행 | 없음 | 운영자 확인 대기 |
| 테스트 B | 미실행 | 미실행 | 미실행 | 미실행 | 없음 | 운영자 확인 대기 |

## 모바일·재배포 확인

- [ ] 모바일 Discord에서 첫 안내, 메뉴, 버튼, 2,000자 분할이 잘리지 않습니다.
- [ ] 안전 큐 버튼에 원문이나 민감값이 표시되지 않습니다.
- [ ] Railway Volume 재배포 전후 DM 로그·큐·정리 상태 건수가 같습니다.
- [ ] `/운영현황`의 오늘/7일 수치와 `/admin` 읽기 API를 같은 시각 기준으로 대조했습니다.
- [ ] 두 운영자가 같은 큐 항목을 처리하면 두 번째 운영자에게 충돌 안내가 보입니다.
