# 프로젝트 리디파인 운영진 문의 대응 템플릿

프로젝트 리디파인 디스코드 운영 중 운영진이 참여자 문의, 익명 고민, 봇 미응답 질문, 커뮤니티 상황에 대응할 때 참고할 수 있는 답변 문구 모음입니다.

## 1. 사용 방법

아래 문구는 운영진이 디스코드 문의 채널, DM, 익명고민채널, 봇 질문로그를 확인한 뒤 그대로 복사해 사용할 수 있도록 작성했습니다.

상황에 맞게 이름, 날짜, 장소, 채널명, 링크, 담당자명만 수정해 주세요. 참여자의 개인 상황, 안전 문제, 특정인과 관련된 내용이 포함된 경우에는 템플릿만으로 바로 답하지 말고 운영진 내부 확인 후 대응해 주세요.

특히 위기 표현, 개인정보 노출, 반복 DM 신고, 혐오·차별·성적 콘텐츠, 사칭·스팸·금전 거래 의심, 공개 채팅방 갈등은 운영진이 함께 확인한 뒤 필요한 조치를 정하는 것이 안전합니다.

## 2. 봇이 답변하지 못한 질문 대응

상황: `#봇-질문로그`에 답변 실패 질문이 올라온 경우

### 질문 확인 후 답변 예정 안내

```text
질문 남겨주셔서 감사합니다. 지금 바로 봇이 답변하지 못한 내용이라 운영진이 확인해 보겠습니다.

확인 후 안내드릴 수 있는 내용은 문의 채널 또는 공지로 다시 정리해 드릴게요. 조금만 기다려 주세요.
```

### FAQ/지식창고 보강 예정 안내

```text
알려주셔서 감사합니다. 이 질문은 앞으로 다른 참여자에게도 도움이 될 수 있어서 FAQ나 지식창고에 보강할 수 있는지 운영진이 확인해 보겠습니다.

우선 지금 필요한 안내는 운영진이 직접 확인 후 답변드릴게요.
```

### 질문이 모호해서 추가 확인이 필요한 경우

```text
질문을 확인했는데, 어떤 상황을 말씀하신 건지 조금 더 확인이 필요해 보여요.

가능한 만큼만 알려주셔도 괜찮습니다. 예를 들어 어떤 활동, 일정, 채널, 상황과 관련된 질문인지 짧게 덧붙여 주시면 운영진이 더 정확히 안내드릴 수 있어요.
```

### 운영진 확인이 필요한 질문인 경우

```text
이 내용은 운영 기준이나 개인 상황에 따라 안내가 달라질 수 있어서 운영진 확인이 필요합니다.

지금 바로 단정해서 답변드리기보다 내부 확인 후 안내드릴게요. 확인되는 대로 다시 말씀드리겠습니다.
```

## 3. 처음 입장한 참여자 문의 대응

상황: 참여자가 "뭐부터 해야 하나요?", "디스코드가 어려워요"라고 묻는 경우

### 처음 들어온 참여자 환영

```text
어서 오세요. 처음 들어오면 채널이 많아 보여서 낯설 수 있어요.

처음부터 모든 내용을 다 확인하거나 바로 활발히 참여하지 않아도 괜찮습니다. 천천히 둘러보면서 익숙해져도 됩니다.
```

### `/안내`, `/채널안내` 안내

```text
먼저 `/안내`를 확인해 보시면 처음 무엇부터 보면 좋을지 안내를 받을 수 있어요.

채널이 헷갈릴 때는 `/채널안내`를 사용해 주세요. 주요 채널이 어떤 용도로 쓰이는지 확인할 수 있습니다.
```

### 모든 채널을 다 보지 않아도 된다는 안내

```text
모든 채널을 한 번에 다 보지 않아도 괜찮아요.

먼저 공지와 일정처럼 운영에 필요한 안내부터 천천히 확인해 주세요. 나머지 채널은 여유가 생겼을 때 필요한 만큼 둘러보면 됩니다.
```

### 디스코드가 어려운 경우

```text
디스코드가 처음이면 어렵게 느껴질 수 있어요. 괜찮습니다.

명령어 사용이나 채널 위치가 헷갈리면 이 문의 채널에 짧게 남겨 주세요. 운영진이 확인하고 천천히 안내드릴게요.
```

## 4. 결석 / 지각 / 불참 문의 대응

상황: 결석, 지각, 중간 퇴장, 컨디션 문제

### 결석 가능 여부 확인

```text
알려주셔서 감사합니다. 참여가 어려운 날이 있을 수 있어요.

오늘 불참으로 확인하겠습니다. 세부 기준이나 이후 안내가 필요한 경우 운영진이 다시 말씀드릴게요. 무리하지 말고 컨디션을 먼저 살펴 주세요.
```

### 지각 안내

```text
알려주셔서 감사합니다. 늦을 수 있는 상황 확인했습니다.

도착 가능 시간이나 참여 가능한 시점이 확인되면 짧게만 남겨 주세요. 운영진이 진행 상황에 참고하겠습니다.
```

### 중간 퇴장 안내

```text
네, 중간에 나가야 하는 상황이 있으면 무리해서 끝까지 남아 있지 않아도 괜찮습니다.

가능한 시점에 운영진에게 짧게 알려 주세요. 갑자기 나가야 하는 경우도 확인되는 대로 말씀해 주시면 됩니다.
```

### 컨디션이 좋지 않은 날의 답변

```text
컨디션이 좋지 않다면 쉬어 가도 괜찮습니다.

오늘은 무리해서 참여하기보다 몸과 마음 상태를 먼저 살펴 주세요. 필요한 안내가 있으면 운영진이 다시 정리해 드릴게요.
```

### 반복 결석이 있을 때 조심스럽게 확인하는 문구

```text
최근 참여가 어려운 날이 이어져서, 운영진이 조심스럽게 상황을 확인하고 싶습니다.

이유를 자세히 말하지 않아도 괜찮아요. 다만 앞으로 참여 방식 조정이나 안내가 필요할 수 있어서, 가능한 만큼만 현재 상태를 알려주시면 함께 확인해 보겠습니다.
```

## 5. 참여 부담 문의 대응

상황: 말하기 부담, 자기소개 부담, 음성채널 부담, 미션 부담

### 말하지 않아도 괜찮다는 안내

```text
처음부터 말을 많이 하지 않아도 괜찮습니다.

읽기, 이모지 반응, 짧은 질문처럼 부담이 적은 방식으로도 참여할 수 있어요. 편한 속도로 머물러 주세요.
```

### 이모지 반응만 해도 된다는 안내

```text
네, 이모지 반응만 남겨도 괜찮습니다.

말로 답하기 어려운 날에는 이모지나 짧은 확인만으로도 충분할 수 있어요. 다만 꼭 확인이 필요한 공지는 운영진 안내에 맞춰 반응해 주세요.
```

### 음성채널 듣기만 해도 되는지 안내

```text
음성채널 참여 방식은 모임마다 다를 수 있지만, 말하기가 부담된다면 듣기 위주로 가능한지 운영진이나 진행자와 함께 확인해 볼 수 있어요.

마이크를 항상 켜야 하는 것은 아니니, 부담되는 부분을 필요한 만큼만 알려 주세요.
```

### 미션을 놓쳤을 때 답변

```text
미션을 놓친 날이 있어도 괜찮습니다.

미션은 평가나 숙제가 아니라 참여를 돕기 위한 장치에 가까워요. 가능한 날에 편한 속도로 이어가 주세요.
```

### 랭킹이나 포인트가 부담될 때 답변

```text
랭킹이나 포인트가 부담스럽게 느껴질 수 있어요.

포인트와 랭킹은 비교나 평가가 아니라 가벼운 재미 요소로 운영하려고 합니다. 부담이 크다면 잠시 보지 않거나 참여하지 않아도 괜찮고, 필요한 조정이 있으면 운영진에게 알려 주세요.
```

## 6. 익명고민채널 대응

상황: 익명으로 남긴 고민, 부담되는 질문, 개인적인 이야기

### 고민을 남겨줘서 고맙다는 답변

```text
고민을 남겨주셔서 감사합니다.

이야기하기 어려운 내용을 꺼내는 것 자체가 쉽지 않았을 수 있어요. 남겨주신 내용은 운영진이 확인하고, 필요한 안내가 있으면 조심스럽게 답변드리겠습니다.
```

### 즉시 답변이 어려울 때 안내

```text
남겨주신 내용을 확인했습니다.

지금 바로 답변드리기보다는 운영진이 함께 확인한 뒤 안내드리는 것이 좋을 것 같아요. 조금 시간이 걸릴 수 있지만, 확인 후 가능한 방식으로 답변드리겠습니다.
```

### 더 자세한 확인이 필요한 경우

```text
남겨주신 내용만으로는 상황을 정확히 파악하기 어려운 부분이 있습니다.

가능하다면 운영진 문의 채널이나 운영진이 안내한 DM 방식으로 조금만 더 알려 주세요. 자세히 설명하기 어렵다면 핵심만 짧게 남겨도 괜찮습니다.
```

### 익명 채널만으로 대응하기 어려운 경우

```text
이 내용은 익명 채널 답변만으로는 안전하게 확인하기 어려울 수 있습니다.

개인 상황 확인이나 즉시 도움이 필요한 내용일 수 있어서, 가능하다면 운영진에게 직접 알려 주세요. 필요한 만큼만 말해도 괜찮고, 운영진이 조심스럽게 확인하겠습니다.
```

### 타인을 특정하거나 비난하는 내용이 포함된 경우

```text
익명 채널에서도 특정 사람을 알아볼 수 있게 적거나 비난하는 내용은 조심해 주세요.

불편한 상황을 알리는 것은 괜찮지만, 운영진이 확인할 수 있도록 상황 중심으로 남겨 주시면 좋겠습니다. 특정인과 관련된 문제는 운영진 문의 채널에서 안전하게 확인하겠습니다.
```

## 7. DM 관련 문의 대응

상황: DM을 보내도 되는지, 불편한 DM을 받았는지, 반복 연락이 있는지

### 운영진에게 DM해도 되는 경우

```text
개인정보가 포함되어 있거나 공개 채팅방에 남기기 어려운 내용이라면 운영진이 안내한 DM 방식을 이용해도 괜찮습니다.

급하지 않은 일반 문의는 문의 채널에 남겨 주시면 놓치지 않고 순차적으로 확인하기 좋습니다.
```

### 참여자 간 DM 예절 안내

```text
참여자 간 DM은 상대가 괜찮아하는지 먼저 살피는 것이 중요합니다.

답장이 늦거나 반응이 없다면 반복해서 보내기보다 멈춰 주세요. 친해지고 싶은 마음이 있어도 사적인 접근은 상대에게 부담이 될 수 있습니다.
```

### 불편한 DM을 받았을 때

```text
불편한 DM을 받았다면 혼자 참고 있지 않아도 괜찮습니다.

가능하면 메시지를 더 이어가지 말고 운영진에게 알려 주세요. 운영진이 상황을 확인하고 필요한 안내를 드리겠습니다.
```

### 반복 연락이나 사적인 접근이 있었을 때

```text
반복 연락이나 사적인 접근이 있었다면 운영진이 확인해 보겠습니다.

상황을 자세히 설명하기 어렵다면 "반복 연락이 있어 불편합니다" 정도로만 먼저 알려주셔도 괜찮아요. 필요한 내용은 운영진이 조심스럽게 추가 확인하겠습니다.
```

### 캡처와 상황 설명을 요청하는 문구

```text
확인을 위해 가능하다면 관련 DM 캡처와 대략적인 상황을 운영진에게 전달해 주세요.

언제, 어떤 방식으로 연락이 왔는지, 어느 부분이 불편했는지 필요한 만큼만 알려주시면 됩니다. 전달해 주신 내용은 상황 확인을 위해 조심스럽게 다루겠습니다.
```

## 8. 커뮤니티 규칙 관련 대응

상황: 반말, 욕설, 비하, 캡처 공유, 과한 친목, 채널 성격 위반

### 가벼운 안내

```text
리디파인에서는 서로의 속도와 거리감을 위해 존댓말과 조심스러운 표현을 기본으로 하고 있습니다.

처음이라 헷갈릴 수 있어요. 앞으로는 커뮤니티 약속에 맞춰 조금 더 조심해서 이야기해 주세요.
```

### 재발 방지 요청

```text
해당 표현이나 행동은 다른 참여자에게 부담이 될 수 있어 운영진이 안내드립니다.

앞으로 같은 상황이 반복되지 않도록 주의해 주세요. 필요하면 운영진이 커뮤니티 약속을 다시 안내드리겠습니다.
```

### 공개 채팅방에서 논쟁이 길어진 경우

```text
현재 대화가 공개 채팅방에서 길어지며 서로에게 부담이 될 수 있어 운영진이 잠시 정리하겠습니다.

추가로 이야기할 내용이 있다면 공개 채팅방에서 이어가기보다 운영진 문의 채널로 남겨 주세요. 운영진이 확인 후 필요한 안내를 드리겠습니다.
```

### 채널 성격에 맞지 않는 대화가 이어지는 경우

```text
이 채널은 주제가 정해져 있어, 지금 대화는 다른 채널에서 이어가는 것이 더 적절해 보입니다.

어디에 남기면 좋을지 헷갈리면 운영진에게 물어봐 주세요. 필요한 경우 운영진이 맞는 채널을 안내드리겠습니다.
```

### 운영진 조치가 필요할 수 있다는 문구

```text
커뮤니티 안전을 위해 운영진이 상황을 확인하겠습니다.

확인 결과에 따라 안내, 메시지 정리, 이용 제한 등 필요한 조치가 있을 수 있습니다. 자세한 내용은 운영진 내부 확인 후 안내드리겠습니다.
```

## 9. 불편한 상황 신고 대응

상황: 불편한 말, 혐오 표현, 위협, 선정적 내용, 스팸, 사칭, 금전 거래 의심 등

### 신고 접수 확인

```text
불편한 상황을 알려주셔서 감사합니다.

운영진이 내용을 확인하겠습니다. 혼자 대응하려고 애쓰지 않아도 괜찮습니다.
```

### 반응하지 말고 운영진에게 알려달라는 안내

```text
해당 상황에는 직접 반응하지 말고 운영진에게 알려 주세요.

대화가 길어지면 더 부담스러워질 수 있어요. 운영진이 확인하고 필요한 방식으로 안내하겠습니다.
```

### 캡처와 채널 위치 요청

```text
확인을 위해 가능하다면 어느 채널에서 있었는지, 대략 언제였는지, 관련 캡처가 있는지 알려 주세요.

캡처는 외부 공유가 아니라 운영진 확인을 위한 용도로만 전달해 주세요.
```

### 운영진 내부 확인 후 조치 안내

```text
전달해 주신 내용은 운영진 내부에서 확인하겠습니다.

확인 결과에 따라 안내, 메시지 정리, 이용 제한 등 필요한 조치가 있을 수 있습니다. 진행 상황은 가능한 범위에서 안내드릴게요.
```

### 공개 채팅방에서 갈등을 이어가지 말라는 안내

```text
이 내용은 공개 채팅방에서 계속 이어가기보다 운영진이 확인하는 편이 안전해 보입니다.

추가 설명이 필요하면 운영진 문의 채널로 남겨 주세요. 공개 채팅방에서는 대화를 잠시 멈춰 주세요.
```

## 10. 참여 중단 / 탈퇴 고민 대응

상황: 참여자가 그만두고 싶다고 말하거나 공개 채팅방에 이탈 의사를 남긴 경우

### 참여 중단을 고민할 수 있다는 인정

```text
참여를 계속할지 고민되는 마음이 생길 수 있습니다.

그 마음이 잘못된 것은 아니에요. 지금 상황에서 어떤 방식이 덜 부담스러울지 운영진과 함께 천천히 확인해 볼 수 있습니다.
```

### 공개 채팅방보다 운영진에게 먼저 알려달라는 안내

```text
참여 중단이나 탈퇴와 관련된 내용은 공개 채팅방에 자세히 남기기보다 운영진에게 먼저 알려 주세요.

개인 상황이 포함될 수 있어서 문의 채널이나 운영진이 안내한 DM 방식으로 확인하는 것이 더 안전합니다.
```

### 조용히 정리하고 싶을 때도 가능하다는 안내

```text
조용히 정리하고 싶을 때도 가능합니다.

모든 이유를 자세히 설명하지 않아도 괜찮아요. 필요한 절차나 이후 안내만 운영진이 차분히 도와드리겠습니다.
```

### 사유를 강요하지 않는 문구

```text
사유를 길게 말하지 않아도 괜찮습니다.

"참여를 잠시 멈추고 싶습니다" 정도로만 알려주셔도 운영진이 필요한 안내를 드릴 수 있어요.
```

### 필요한 경우 추후 연락 방식 확인

```text
이후 안내가 필요한 경우 어떤 방식으로 연락드리면 편할지 알려 주세요.

디스코드 문의 채널, 운영진이 안내한 DM 방식, 별도 연락 방법 중 편한 방식을 기준으로 확인하겠습니다.
```

## 11. 가족 / 친구 초대 부담 대응

상황: Redefine Day, 결과 공유, 가족·친구 초대가 부담되는 경우

### 부담을 느낄 수 있다는 인정

```text
가족이나 친구 초대가 부담스럽게 느껴질 수 있습니다.

초대나 공개가 모두에게 편한 방식은 아니기 때문에, 그 마음을 운영진에게 알려주셔도 괜찮아요.
```

### 초대 여부나 방식 조율 안내

```text
초대 여부, 공개 범위, 참여 방식은 운영진과 함께 확인해 볼 수 있습니다.

아직 확정되지 않은 부분이 있을 수 있으니, 부담되는 지점을 필요한 만큼만 알려 주세요. 가능한 방식이 있는지 함께 살펴보겠습니다.
```

### 운영진 안내 기준으로 확인

```text
Redefine Day의 자세한 일정, 초대 범위, 진행 방식은 운영진 공지를 기준으로 확인해 주세요.

변경 사항이 있으면 공지 채널을 통해 안내드리겠습니다.
```

## 12. 정신건강 / 위기 상황 대응

상황: 힘들다, 위험한 마음이 든다, 혼자 감당하기 어렵다는 표현이 있는 경우

주의: 아래 문구는 의료적 진단, 치료 조언, 심리상담을 대신하지 않습니다. 위급하거나 안전이 걱정되는 경우 운영진이 직접 확인하고 필요한 도움으로 연결하는 방향으로 사용해 주세요.

### 혼자 감당하지 않아도 된다는 문구

```text
지금 마음이 많이 힘든 상태라면 혼자 감당하지 않아도 됩니다.

이야기해 주셔서 감사합니다. 운영진이 조심스럽게 확인하겠습니다.
```

### 운영진이 직접 확인하겠다는 문구

```text
남겨주신 내용은 운영진이 직접 확인하겠습니다.

지금 안전이 걱정되는 상황인지, 혼자 있는지, 바로 도움이 필요한지 가능한 만큼만 알려 주세요. 자세히 설명하기 어렵다면 "지금 안전 확인이 필요합니다"라고만 남겨도 괜찮습니다.
```

### 봇이나 디스코드 답변만으로 해결하지 않겠다는 안내

```text
이 내용은 봇 답변이나 디스코드 메시지만으로 해결하려고 하지 않겠습니다.

운영진이 확인하고, 필요한 경우 주변 사람, 보호자, 긴급 지원, 전문기관 도움으로 연결할 수 있도록 안내하겠습니다.
```

### 위급하거나 안전이 걱정되는 경우

```text
지금 바로 스스로를 해칠 것 같거나 안전이 걱정되는 상황이라면 디스코드 답변을 기다리지 말고 즉시 도움을 요청해 주세요.

주변의 신뢰할 수 있는 사람, 보호자, 긴급 지원, 전문기관에 바로 연결해 주세요.

운영진 확정 후 추가할 정보:
- 긴급 연락처: [긴급 연락처 입력]
- 지역 전문기관: [기관명 / 연락처 입력]
- 야간 또는 주말 지원 경로: [지원 경로 입력]
```

### 의료적 판단을 피하는 문구

```text
운영진은 의료적 진단이나 치료 조언을 대신할 수는 없습니다.

다만 지금 필요한 안전 확인과 연결을 함께 도울 수 있습니다. 전문적인 도움이 필요할 수 있는 상황이라면 운영진이 확인 후 적절한 도움 경로를 안내하겠습니다.
```

## 13. 운영진 답변이 늦어질 때

상황: 문의가 많거나 바로 확인하기 어려운 경우

### 확인이 늦어진 것에 대한 사과

```text
답변이 늦어져 죄송합니다.

남겨주신 내용은 확인 중입니다. 조금만 더 기다려 주시면 운영진이 안내드리겠습니다.
```

### 순차적으로 확인 중이라는 안내

```text
현재 문의가 여러 건 있어 순차적으로 확인하고 있습니다.

놓치지 않도록 확인하고 있으니 조금만 기다려 주세요.
```

### 급한 내용이면 다시 표시해달라는 안내

```text
혹시 일정, 안전, 당일 참여 여부처럼 급한 내용이라면 메시지에 "급한 문의"라고 다시 표시해 주세요.

운영진이 우선 확인이 필요한지 살펴보겠습니다.
```

### 놓치지 않도록 확인하겠다는 문구

```text
남겨주신 문의는 놓치지 않도록 확인하겠습니다.

바로 답변드리기 어려운 내용은 내부 확인 후 다시 안내드릴게요.
```

## 14. 일정 / 장소 / 준비물 문의 대응

상황: 일정, 장소, 준비물, 변경사항 문의

### 최신 공지 기준 안내

```text
일정, 장소, 준비물은 최신 공지를 기준으로 확인해 주세요.

변경 사항이 있을 수 있어서 참여 전에는 공지 채널을 한 번 더 확인하는 것을 권장합니다.
```

### 아직 확정되지 않은 경우

```text
해당 내용은 아직 확정 전이라 지금 바로 안내드리기 어렵습니다.

운영진 확인 후 확정되는 대로 공지 채널에 안내드리겠습니다.
```

### 변경 시 공지 채널 안내

```text
일정이나 장소가 변경될 경우 공지 채널에 다시 안내드리겠습니다.

참여 전에는 최신 공지와 고정 메시지를 기준으로 확인해 주세요.
```

### 준비물이 없는 경우에도 회차별 공지 확인

```text
현재 안내된 별도 준비물은 없습니다.

다만 회차별로 준비물이 달라질 수 있으니, 참여 전 최신 공지를 한 번 더 확인해 주세요.
```

## 15. 짧은 답변 모음

- 확인해주셔서 감사합니다. 운영진이 확인 후 안내드릴게요.
- 지금 바로 답변드리기 어려운 내용이라 내부 확인 후 다시 안내드리겠습니다.
- 처음부터 활발히 참여하지 않아도 괜찮습니다. 천천히 둘러봐 주세요.
- 모든 채널을 한 번에 다 확인하지 않아도 괜찮아요.
- 필요한 만큼만 알려주셔도 괜찮습니다.
- 해당 내용은 공개 채팅방보다 운영진 문의 채널로 남겨주시면 더 안전하게 확인할 수 있어요.
- 불편한 상황을 알려주셔서 감사합니다. 운영진이 확인하겠습니다.
- 가능하다면 관련 채널 위치와 캡처를 운영진에게 전달해 주세요.

- 랭킹이나 포인트가 부담되면 잠시 보지 않아도 괜찮습니다.
- 참여를 잠시 멈추고 싶다면 운영진에게 먼저 알려 주세요.
- 사유를 길게 설명하지 않아도 괜찮습니다.
- 위급하거나 안전이 걱정되는 상황이라면 디스코드 답변을 기다리지 말고 즉시 도움을 요청해 주세요.
- 운영진은 의료적 판단을 대신할 수는 없지만, 필요한 도움으로 연결할 수 있도록 확인하겠습니다.

## 16. 운영진 내부 확인이 필요한 상황 목록

아래 상황은 템플릿만으로 답하지 말고 운영진 내부 확인 후 대응해 주세요.

- [ ] 자해, 자살, 위험한 마음, 안전 우려 등 위기 표현이 있는 경우
- [ ] 반복 DM, 원치 않는 사적 연락, 스토킹처럼 느껴질 수 있는 신고
- [ ] 혐오, 차별, 성적 콘텐츠, 폭력적 표현이 포함된 경우
- [ ] 사칭, 스팸, 금전 거래, 불법 링크 공유가 의심되는 경우
- [ ] 참여 중단, 탈퇴, 장기 불참과 관련된 민감한 개인 사정
- [ ] 실명, 연락처, 주소, 건강 정보 등 개인정보가 노출된 경우
- [ ] 익명 글이나 공개 글에서 타인을 특정할 수 있는 내용이 있는 경우
- [ ] 공개 채팅방에서 갈등이나 논쟁이 길어지는 경우
- [ ] 운영 기준, 일정, 참여 자격처럼 단정 답변이 어려운 경우
- [ ] 외부 기관, 보호자, 긴급 지원 연결이 필요할 수 있는 경우

## 17. 답변 전 확인 체크리스트

운영진이 답변하기 전에 아래 항목을 먼저 확인해 주세요.

- [ ] 이 답변을 공개 채널에 남기는 것이 적절한가요?
- [ ] DM 또는 운영진 문의 채널로 옮기는 것이 더 안전한가요?
- [ ] 참여자의 개인정보가 포함되어 있나요?
- [ ] 다른 사람을 특정하거나 알아볼 수 있는 내용이 있나요?
- [ ] 운영진 내부 확인이 필요한 사안인가요?
- [ ] 답변이 참여자를 평가하거나 압박하는 표현을 담고 있지 않나요?
- [ ] "반드시", "당연히", "문제입니다"처럼 단정적인 표현을 줄였나요?
- [ ] 위급하거나 안전이 걱정되는 내용이라면 실시간 도움 안내가 포함되어 있나요?
- [ ] 봇이나 운영진이 의료적 판단, 치료 조언, 심리상담을 대신하는 표현을 쓰지 않았나요?
- [ ] 날짜, 장소, 채널명, 링크가 실제 운영 안내와 일치하나요?
