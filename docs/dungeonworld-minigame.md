# 던전월드 솔로 미니게임

`/던전월드`는 참여자가 디스코드 안에서 혼자 짧게 즐기는 텍스트 어드벤처 미니게임입니다. 운영진이 따로 진행하는 실제 던전월드(Dungeon World 기반) TRPG 캠페인을 1~12회차의 짧은 솔로 장면으로 압축해, 주차별로 한 회차씩 열어 보는 구조입니다.

## 왜 만들었나

- 지금 디스코드에서 참여자가 느낄 수 있는 재미는 미니게임 정도이고, 기존 미니게임(카드뽑기, 가위바위보 등)은 모두 1회성 즉답형입니다.
- 오프라인 모임이나 실제 TRPG 세션에 나오기 어려운 참여자, 특히 고립청년에게는 이런 가벼운 콘텐츠가 디딤돌 역할을 할 수 있습니다.
- 다만 이 콘텐츠가 오프라인 참여를 대체하는 게 아니라 보완하는 디딤돌로 남아야 합니다. 그래서 포인트를 지급하지 않습니다 — 보상이 매력적일수록 "굳이 오프라인에 안 나가도 되는 이유"가 될 위험이 있기 때문입니다.

## 동작 방식

1. `/던전월드` 실행 시 현재 열린 회차의 도입부와 선택지 3개를 보여줍니다.
2. 선택지를 누르면 2d6(주사위 2개)을 굴려 합계로 결과 등급을 정합니다.
   - 10+: 원하는 대로 풀림
   - 7~9: 해내지만 대가가 생김
   - 6-: 예상과 다른 전개
3. 등급에 맞는 결과 텍스트와 다음 회차로 이어지는 짧은 안내(`closingNote`)를 보여줍니다.
4. 모든 참여자 응답은 본인에게만 보이는 ephemeral 응답입니다.
5. `/던전월드기록`을 실행하면 본인의 던전월드 진행 기록만 private/ephemeral 응답으로 확인할 수 있습니다.

**포인트는 지급되지 않습니다.** 일일 캡, 중복 방지 같은 점수 관련 로직이 전혀 필요 없는 구조입니다.

## 기록과 보고서

- 모든 플레이(선택, 주사위, 결과 등급)는 `data/dungeonworld-logs.local.json`에 기록됩니다. 구현은 `src/dungeonworld.js`입니다.
- 참여자는 `/던전월드기록`으로 총 플레이 수, 완료한 회차 수, 현재 열린 회차, 현재 회차 참여 여부, 현재 인트로에 영향을 주는 직전 회차 결과, 회차별 최신 결과를 확인할 수 있습니다. 다른 참여자의 기록은 보이지 않습니다.
- 운영자는 `/운영내보내기 종류:던전월드`로 요약/JSON/CSV 형태로 기록을 받아볼 수 있습니다. 기존 `/운영내보내기`의 형식/개수 옵션을 그대로 사용합니다.
- 요약과 JSON 내보내기에는 전체 플레이 수, 고유 참여자 수, 회차별 플레이 수, 결과 등급 분포, 선택 분포, 최신 회차 진행 수가 포함됩니다.
- CSV는 기존 플레이 로그 행 형태를 유지합니다. `기록ID`, `사용자ID`, `표시이름`, `회차ID`, `선택내용`, 주사위, 결과, 생성일시를 행 단위로 내려받는 용도입니다.
- 이 로그는 점수나 순위가 아니라 콘텐츠 반응을 살펴보기 위한 운영 참고용입니다.

## 콘텐츠 범위

- 1회차("변방 여관의 검은 종")부터 12회차("새 지도의 첫 줄")까지 캠페인 본편과 에필로그 콘텐츠가 `src/dungeonworld.js`의 `SESSIONS`에 등록되어 있습니다. 캐릭터/클래스 시스템, 다단계 분기는 아직 없습니다.
- 모든 회차가 3가지 접근 방식(위기 넘기기/살펴보기/말로 풀기)만으로 2d6 판정을 진행합니다.
- 회차 노출 시점은 아래 "회차 자동 오픈과 운영자 오버라이드"를 따릅니다.
- 에필로그 반응을 본 뒤 새 시즌이나 클래스 선택을 다음 단계로 검토할 수 있습니다.

## 브라우저 생존전 자료 반영

`public/dungeonworld-survivors/`의 `검은 종 생존전`은 위 Discord 텍스트 게임과 별도인 정적 브라우저 미니게임입니다. 참고 TRPG 자료는 보상이나 계정 기록이 아니라 전투 표면의 감각으로만 반영합니다.

- 던전월드 기본 액션의 10+/7~9/6- 구조를 웨이브 전환 2d6 판정으로 번역했습니다. 10+는 흐름을 잡아 회복과 긴장 완화가 생기고, 7~9는 해내지만 긴장이 오르며, 6-는 추가 압박이 들어옵니다.
- 던전월드 플레이북 감각은 시작 시 전사/사제/도적/드루이드/마법사/레인저 선택으로 압축했습니다. 각 플레이북은 근력/민첩/지혜/정신력 보정, 기본 공격, 생존 방식이 다릅니다.
- 플레이북은 성장 중에도 업그레이드 경로를 나누어 해금합니다. 전사는 근접/방패, 사제는 회복/의식, 도적은 기동/단검, 드루이드는 주술/제어, 마법사는 관통 주문, 레인저는 원거리/동료 매 방향으로 갈라집니다.
- 크툴루/죽음의 빛 자료의 압박감은 체력과 별개인 `긴장` 수치로만 반영했습니다. 긴장이 한계에 닿으면 짧은 피해와 흔들림이 발생합니다.
- GURPS와 크툴루 캐릭터 시트의 상태 추적 감각은 사이드 패널의 작은 캐릭터 시트와 어두운 룰북형 UI로 반영했습니다.
- 이 브라우저 생존전은 포인트 지급, Discord 계정 연동, 운영 데이터 저장을 하지 않습니다.

## 회차 자동 오픈과 운영자 오버라이드

- `DUNGEONWORLD_START_DATE`(캠페인 시작일, `YYYY-MM-DD`)를 설정하면 시작일 기준 경과 주차에 맞는 회차를 자동으로 엽니다. 시작일 당일부터 6일째까지는 1회차이고, 7일이 지나면 2회차로 넘어갑니다. 비워두거나 잘못된 날짜이면 항상 1회차입니다.
- 회차 수보다 더 많은 주가 지나면 마지막으로 등록된 회차에 고정됩니다.
- 10~12회차 에필로그도 같은 주간 자동 오픈 규칙에 포함됩니다. 이미 `DUNGEONWORLD_START_DATE` 기준 9주 이상 지난 서버라면 코드 배포 직후 10~12회차 중 해당 주차가 열릴 수 있으므로, 순차 공개를 원할 때는 배포 전 `/던전월드관리` 오버라이드나 시작일 설정을 확인합니다.
- 운영진은 `/던전월드관리`로 현재 회차, 자동 계산 회차, 수동 오버라이드 상태, 다음 자동 오픈 맥락, 전체 회차 ID/제목, 최근 기록 수, 결과 분포, 인기 회차/선택을 확인할 수 있습니다.
- `회차:<회차ID>` 옵션으로 수동 오버라이드를 걸 수 있습니다. `초기화:true`를 주면 오버라이드를 지우고 자동 계산으로 돌아갑니다.
- `/던전월드관리` 화면의 버튼은 이전 회차 수동 설정, 다음 회차 수동 설정, 오버라이드 해제, 새로고침만 제공합니다. 로그 삭제나 초기화 같은 파괴적 작업은 없습니다.
- 오버라이드는 `data/dungeonworld-config.local.json`에 저장됩니다(없으면 `data/dungeonworld-config.example.json`을 기본값으로 사용). 구현은 `createDungeonworldConfigRepository`(`src/dungeonworld.js`)입니다.

## 직전 회차 결과가 다음 회차 인트로에 반영됨

- 각 회차 객체는 `introVariants: { default, strong, mixed, weak }`를 가질 수 있습니다.
- 참여자가 `/던전월드`를 실행하면, 현재 회차의 **바로 이전** 회차에서 그 참여자가 받은 결과 등급(strong/mixed/weak)을 조회해 해당 변형 인트로를 보여줍니다.
- 직전 회차 기록이 없거나(첫 회차, 또는 아직 플레이하지 않음) 해당 등급의 변형이 없으면 `default` 인트로를 보여줍니다.
- 같은 참여자가 직전 회차를 여러 번 플레이했다면 가장 최근 기록의 등급을 기준으로 합니다.
- 선택 로직은 `pickIntroForSession`, 직전 회차 조회는 `getPreviousSessionId` + `dungeonworldRepository.getLastPlayForUserInSession`(둘 다 `src/dungeonworld.js`)입니다.

## 로컬 검증 기준

- `node scripts/test-dungeonworld-flow.js`: `/던전월드` 실행, 선택지 클릭, 플레이 로그 저장, `/던전월드기록`, `/던전월드관리` 버튼 흐름, `/운영내보내기 종류:던전월드` 요약/JSON/CSV, 운영자 권한 확인을 검증합니다.
- `node scripts/test-dungeonworld-sessions.js`: 자동 회차 계산, `/던전월드관리` 오버라이드 저장/초기화, 직전 회차 ID, 인트로 변형 선택, 직전 회차 결과 조회, 진행/집계 헬퍼를 검증합니다.
- `node scripts/test-dungeonworld-session-02.js`부터 `node scripts/test-dungeonworld-session-12.js`까지: 2~12회차의 제목, 인트로, closing note, 선택지 3개, 결과 텍스트 길이와 NPC 대사를 검증합니다.
- `npm run check:release`: 위 Dungeon World 테스트와 `src/dungeonworld.js`, `scripts/test-dungeonworld-*.js` 문법 검사를 포함한 릴리즈 게이트입니다.

## 배포 주의사항

- `/던전월드`, `/던전월드기록`, `/던전월드관리`는 Slash Command이므로 `src/deploy-commands.js` 변경 후 `npm run deploy`를 실행해야 실제 서버에 명령어가 나타납니다.
- `/운영내보내기`의 `종류` 선택지에 `던전월드`를 추가했으므로, 이 선택지가 보이려면 마찬가지로 `npm run deploy`가 필요합니다.
- 문서만 수정한 경우에는 `npm run deploy`를 실행하지 않습니다. 명령어 구조 변경이 반영된 코드 배포와 Slash Command 배포 여부를 따로 기록합니다.
