# 프로젝트 리디파인 Discord 온보딩 역할/권한 수동 세팅 가이드

## 문서 목적

이 문서는 72시간 온보딩 구조를 실제 Discord 서버 권한에 반영하기 위한 운영자용 수동 세팅 가이드입니다.

`onboarding-role-channel-plan.md`의 역할/채널 구조와 현재 봇 안내 구조를 기준으로, 운영진이 Discord 서버에서 역할과 채널 보기 권한을 직접 설정할 때 참고할 수 있도록 정리합니다. 이 문서는 실제 Discord 권한 설정을 변경하지 않으며, 봇 코드나 데이터 수정도 포함하지 않습니다.

## 1. 기본 원칙

- 참여자에게 내부 척도나 분류를 드러내지 않습니다.
- 역할명은 낙인 없는 중립 표현을 사용합니다.
- 처음부터 모든 채널을 열지 않습니다.
- 운영진 전용 채널은 반드시 숨깁니다.
- 실제 권한 변경 전 운영진 내부 검토가 필요합니다.

## 2. 권장 역할 목록

### 운영진

서버 운영, 공지 게시, 문의 대응, 권한 점검을 담당하는 역할입니다. 운영진 전용 채널과 로그 채널을 볼 수 있어야 합니다.

### 봇

안내 봇이 명령어 응답, 메시지 전송, 로그 기록을 수행하기 위한 역할입니다. 참여자 역할보다 필요한 권한을 안정적으로 적용할 수 있도록 별도 역할로 관리합니다.

### 참여자

온보딩 이후 기본 커뮤니티 참여 권한을 부여하기 위한 역할입니다. 공통 안내 채널과 운영상 공개하기로 한 일반 참여 채널을 볼 수 있습니다.

### 온보딩-천천히

진입 부담을 낮추고 공지 확인, 익명 고민, 운영진 문의 중심으로 적응할 수 있게 하는 역할입니다. 초반에는 활동 채널을 제한하거나 읽기 중심으로 운영할 수 있습니다.

### 온보딩-기본

공지 확인, 가벼운 대화, 미션, 출석까지 무리 없이 경험할 수 있게 하는 역할입니다. 활동을 강요하지 않고 필요한 채널을 단계적으로 열어줍니다.

### 온보딩-활동

자유채팅, 챌린지, 출석, 포인트, 랭킹 등 활동형 채널을 비교적 넓게 경험할 수 있게 하는 역할입니다. 음성채널은 운영진 판단에 따라 단계적으로 공개합니다.

## 3. 역할 우선순위 권장

아래 순서를 기본 권장안으로 사용합니다.

1. 운영진
2. 봇
3. 참여자
4. 온보딩-활동
5. 온보딩-기본
6. 온보딩-천천히

단, 실제 서버의 기존 역할 구조, 봇 역할 위치, 관리자 권한 정책에 따라 운영진이 조정할 수 있습니다.

## 4. 공통으로 보여줄 채널

아래 채널은 온보딩 역할과 참여자 역할에서 공통으로 볼 수 있도록 검토합니다.

- 환영-인사와-규칙
- 참여동의-확인
- 이름표-색상-고르기
- 프로젝트공지_일정및안내
- 공지_관리자-공지

## 5. 온보딩-천천히 권한 예시

- 처음 안내와 공지 중심으로 볼 수 있게 설정합니다.
- 익명고민채널 접근을 허용합니다.
- 운영진 문의 채널 접근을 허용합니다.
- 자유채팅방, 포인트, 랭킹, 음성채널은 초반 제한 또는 읽기 전용 운영을 검토합니다.

## 6. 온보딩-기본 권한 예시

- 자유채팅방 접근을 허용합니다.
- 환영해주세요 접근을 허용합니다.
- 오늘의-미션, 매일출석체크 접근을 허용합니다.
- 포인트/랭킹은 필요 시 제한적으로 공개합니다.

## 7. 온보딩-활동 권한 예시

- 자유채팅방 접근을 허용합니다.
- 매일-챌린지 접근을 허용합니다.
- 오늘의-미션 접근을 허용합니다.
- 매일출석체크 접근을 허용합니다.
- 포인트-상점, 포인트로게임하기, 랭킹확인 접근을 허용합니다.
- 음성채널은 운영진 판단에 따라 단계적으로 공개합니다.

## 8. 운영진 전용 채널 권한

아래 채널은 일반 참여자에게 보이지 않아야 합니다.

- 봇-질문로그
- 운영진-문의대응
- 익명고민 관리 채널

운영진 전용 채널은 `운영진` 역할과 필요한 봇 역할만 접근할 수 있도록 확인합니다. 온보딩 역할, 참여자 역할, 기본 `@everyone` 권한에서는 채널 보기 권한이 없어야 합니다.

## 9. 봇 권한 확인

봇 역할에는 운영에 필요한 최소 권한이 적용되어 있는지 확인합니다.

- 슬래시 명령어 사용
- 메시지 보내기
- 임베드 링크
- 메시지 기록 보기
- 봇-질문로그 채널에 기록 가능
- 공지 명령어는 운영자 권한 기준으로만 사용

봇이 참여자에게 보이지 않아야 하는 운영진 전용 채널 내용을 일반 채널에 노출하지 않도록, 로그 채널 권한과 공지 명령어 사용 권한을 함께 점검합니다.

## 10. 세팅 순서

1. 역할 생성
2. 카테고리 생성 또는 정리
3. 공통 채널 권한 설정
4. 온보딩 역할별 채널 보기 권한 설정
5. 운영진 전용 채널 숨김 확인
6. 봇 권한 확인
7. 테스트 계정으로 역할별 보이는 채널 확인
8. `/안내`, `/채널안내`, `/질문` 테스트
9. 운영진 최종 확인

## 11. 테스트 체크리스트

- 온보딩-천천히 역할에서 보이는 채널
- 온보딩-기본 역할에서 보이는 채널
- 온보딩-활동 역할에서 보이는 채널
- 참여자 역할 전환 후 보이는 채널
- 운영진 전용 채널이 일반 역할에 보이지 않는지
- 봇 명령어가 정상 작동하는지
- 봇-질문로그가 기록되는지

## 12. 주의사항

- 역할명에 고립, 은둔, 위험, 척도 같은 표현을 사용하지 않습니다.
- 채널이 적게 보이는 참여자가 불안해하지 않도록 안내 문구와 함께 운영합니다.
- 실제 권한 변경은 운영진이 직접 확인 후 진행합니다.
- 권한 설정 후에는 반드시 테스트 계정으로 확인합니다.
