# 간식 공방 키우기(방치형) 고도화 백로그

`public/idle/`의 고도화 후보 목록입니다. 착수 시 항목별 계획서를 만듭니다. 공통 원칙: `engine.js`(순수 로직)/`content.js`(밸런스)/`game.js`(DOM) 분리 유지, `lifetimeProduced` 단조 증가 불변(공동 목표 집계의 전제 — **환생 포함 어떤 기능도 이 값을 줄이면 안 됨**).

## 0. 현재 상태

시설 6종·무대 6단계 승급·환생(비법 레시피)·시간제 배달 파견·퀘스트 체인 20개·황금 간식·업적 도감·하단 탭 4. 주간 생산량이 공동 목표에 합산(랭킹 없음). v3 원화 적용, 무대 장면 소품은 이모지 잔존.

## 1. 백로그 (우선순위순)

### I1 — 공동 목표 연동 콘텐츠 [효과 큼 / 소~중]

- 공동 목표 달성 주간에 게임 내 시각 반영(공방 장식·축하 배너) — 서버 `/goal` 응답 재사용, "함께 만든 결과"가 게임 안에서 보이게. 비동기 소셜의 체감을 완성하는 조각.
- 운영 이벤트 주간(예: "이번 주 생산 2배") — env 또는 `/daily`류 서버 값으로 결정적 제어. 공동 목표 달성률 조절 수단도 됨.

### I2 — 파견 콘텐츠 확장 [중 / 중]

- 배달 파견 목적지·보상 다양화, 파견 결과 이야기 카드(스토리북 톤 활용). 방치형의 "돌아왔을 때 반가움"을 키우는 축.

### I3 — 무대 이모지 소품 원화 교체 [중 / 소]

- v3 잔여 폴리시(디자인 v3 완결 시 이월된 항목). 원화 프롬프트 명세는 [webgame-art-prompts.md](webgame-art-prompts.md) 패턴 재사용.

### I4 — 통계·회고 화면 [하 / 소]

- 기록 탭에 주간 생산 추이(CSS 막대 정도), 환생 히스토리. 숫자가 커지는 재미의 가시화.

### I5 — 환생 심화 [하 / 중]

- 레시피 트리 분기(생산/파견/황금 간식 특화). 밸런스 재작업 볼륨 있음 — 참여 데이터로 환생 도달자가 충분할 때.

## 2. 하지 않기로 확인한 것

- 개인 생산량 랭킹 — 방치형은 랭킹 부적합 장르(연동 v1 결정 유지). "함께" 축(공동 목표)만 강화
- 푸시/리마인더로 복귀 유도 — 침묵 존중 원칙과 충돌
