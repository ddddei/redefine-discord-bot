# 덱 게임 비주얼 고도화 v1 계획서 — 전투 무대·의도 아이콘·부채꼴 손패·맵·데스크톱

작성: 2026-07-13. 상태: **승인 대기**. 근거 레퍼런스: Slay the Spire UI 분석(Cloudfall Studios·interfaceingame) — 적·플레이어 대치 구도, 의도 아이콘, 비블로킹 연출, 큰 히트박스, 분기 맵 시각화.

## 0. 배경 / 문제

2026-07-13 사용자 피드백: "너무 모바일 위주 게임 같다, 슬레이 더 스파이어급으로 고도화 필요."

현 상태 진단 (`public/deck/`):

- **플레이어가 화면에 없다** — 전투 화면(`index.html` `#screen-combat`)은 적 패널 + 상태 텍스트 + 카드 목록뿐. "대결" 구도가 아니라 "폼 입력" 구도.
- **의도가 텍스트다** — `다음 행동: 공격 5` 문자열(`game.js` INTENT_LABEL). StS의 핵심 발명인 의도 아이콘 대비 즉독성이 낮다.
- **손패가 가로 스크롤 목록** — `.hand-area { overflow-x: auto }`. 5장 중 2.5장만 보이고 부채꼴 물성이 없다.
- **맵이 세로 원 나열** — `.map-scroll`(column-reverse)에 44px 원 노드. 분기 경로가 선으로 이어지지 않아 "갈림길" 감각이 약하다.
- **데스크톱에서 폭 520px 고정** — `.app-frame { max-width: 520px }`. 와이드 화면에서 여백만 늘어난다.

전제: **모바일 퍼스트는 유지**(주 진입로 Discord 인앱 브라우저 — `webgame-mobile-first-plan.md` 확정 사항). 이 계획은 모바일을 버리는 게 아니라 모바일 물성을 올리고 + 데스크톱에서 판이 넓어지는 반응형 고도화다.

착수 게이트: 없음. 선행: PR #87(방어 이관·라벨 한글화) 머지 — 같은 파일(`deck/game.js`·`styles.css`)을 만지므로 충돌 방지.

## 1. 전체 구조

- 수정 범위: `public/deck/index.html`, `styles.css`, `game.js`(렌더·연출 함수만), `public/shared/assets/`(의도·맵 노드 SVG 신규 ~9종).
- **`engine.js`·`content.js` 효과 정의 무수정. 리플레이 로그 버전 유지** — 카드 해석·전투 판정·맵 생성의 재현 의미가 바뀌지 않는 표시·입력 전용 작업이다. `scripts/test-webgame-replay.js`와 `test-deck*.js`가 무수정 통과해야 한다.
- 저장 스키마: 불변. 환경변수: 없음. `deploy-commands.js`: 무변경 → **머지 후 `npm run deploy` 불필요**.

## 2. 접근 방식

- StS 차용 원칙: ① 적·플레이어가 한 무대에 마주 봄 ② 의도는 아이콘+숫자 ③ 연출은 입력을 막지 않음(복제본 연출 — 기존 카드 사용 연출 원칙 재사용) ④ 탭 타겟은 시각 요소보다 크게(44px+ 유지) ⑤ 맵은 경로가 보이는 분기.
- 에셋은 가이드(`webgame-design-guide.md`) 라인 캐릭터 규칙: SVG, 외곽선 `#4a3524`, 서브 팔레트.
- 애니메이션은 transform/opacity만, `prefers-reduced-motion` 존중, 상시 루프 금지(기존 모션 원칙 4절).
- 단계별 커밋 — 각 단계는 독립 롤백 가능.

## 3. 단계별 계획

### 3-A. 전투 무대 재구성

수정: `index.html`(#screen-combat), `styles.css`, `game.js`(렌더 배선).

- `#screen-combat` 상단을 **무대 존**으로 재구성: 좌하단에 플레이어(기존 `shared-char-baker.webp` 재사용, 지금은 헤더에만 있음)를 배치하고 우상단에 적 아트 창 — 대각 대치 구도. `bg-deck.webp`(이미 body 배경으로 로드됨)가 무대 뒤로 보이게 무대 존은 반투명 패널.
- 플레이어 옆에 체력바(현재 헤더 칩의 수치를 바 형태로 복제 표시)·방어 배지·상태 배지를 부착. 적도 체력바 추가(현재 숫자만).
- 피해/방어 획득 시 숫자 팝 연출(복제 span, 400ms 이하).

### 3-B. 의도 아이콘화

수정: `public/shared/assets/deck-intent-{attack,block,strength,weak,vulnerable}.svg` 신규 5종, `game.js`(의도 렌더), `styles.css`.

- `#enemy-intent`를 아이콘+숫자 배지로: ⚔(라인 스타일) + "5". 텍스트 라벨은 `title`/보조 텍스트로 유지(접근성).
- 아이콘 5종은 가이드 1절 규칙(외곽선 3.0, 서브 팔레트)으로 Fable이 직접 제작 — 기존 `deck-icon-*.svg` 3종과 나란히 놓고 이질감 없어야 함(가이드 1.5절 기준).

### 3-C. 손패 부채꼴 + 사용 가능 표시

수정: `styles.css`, `game.js`(hand 렌더).

- 모바일: 카드 폭을 유지하되 **겹침 부채꼴**(음수 마진 + 미세 회전 ±4°)로 5장이 한 화면에 들어오게. 탭하면 해당 카드가 위로 떠오르며 전체 노출(2탭 사용: 1탭 선택·확대, 2탭 사용 — 오탭 방지 겸용), 가로 스크롤은 제거.
- 에너지 부족 카드는 채도 낮춤 + 코스트 메달 붉게 — "지금 낼 수 있는 것"이 스캔 가능해야 한다.
- 데스크톱(hover 가능 환경): hover 시 카드 확대(1.15x, transform). 기존 `card-enter` 딜-인 연출 유지.

### 3-D. 맵 경로 시각화

수정: `styles.css`, `game.js`(맵 렌더), `public/shared/assets/deck-node-{battle,elite,rest,event,boss}.svg` 신규(이모지 대체) + 필요 시 인라인 SVG 연결선.

- 노드 사이를 **점선 잉크 경로**로 연결(세로 지그재그 — 홀수 층 좌측, 짝수 층 우측 오프셋으로 "길" 감각). 분기 층은 두 갈래 선이 실제로 갈라져 보이게.
- 노드 이모지(🍪⚔️❓☕👑)를 라인 스타일 SVG로 교체. 현재 위치에 플레이어 초상 마커.
- 맵 생성 로직(engine)은 그대로 — 렌더만 오프셋을 준다. **리플레이의 ["m",n] 액션 의미 불변.**

### 3-E. 데스크톱 반응형

수정: `styles.css`(미디어 쿼리 블록 추가).

- `@media (min-width: 900px)`: `.app-frame` max-width 960px로 확장, 전투 화면을 가로 무대(적 우측·플레이어 좌측 나란히) + 하단 중앙 부채꼴 손패(StS 구도)로 재배치. 맵도 2열 확장.
- 모바일 마크업을 공유하고 CSS 그리드 재배치로만 처리 — JS 분기 없음.

### 커밋 구성

단계당 커밋 1개(A~E, 총 5개) + QA 수정. PR 1개.

## 4. 성공 기준

- **S1 (대치 구도)**: 모바일 뷰포트 전투 화면 스크린샷에 플레이어 캐릭터와 적이 함께 보이고, 양쪽에 체력바가 표시된다 (수동 확인 + 사용자 육안 승인).
- **S2 (의도 아이콘)**: 적 의도가 아이콘+숫자로 표시되고, 5종(공격/방어/강화/약화/취약) 모의 전투에서 각각 렌더됨을 확인.
- **S3 (부채꼴)**: 5장 손패가 스크롤 없이 한 화면에 보이고, 1탭 확대→2탭 사용 흐름이 동작. 에너지 부족 카드의 시각 구분 확인.
- **S4 (맵)**: 갈림길 층에서 경로선이 두 갈래로 갈라져 보임. 노드에 이모지 0건.
- **S5 (데스크톱)**: 1280px 뷰포트에서 가로 무대 배치 확인. 375px 회귀 무손상.
- **S6 (로직 불변)**: `engine.js`·`content.js` git diff 0건, `node scripts/test-webgame-replay.js` + `check:release` 전체 통과. 이어하기(런 저장) 하위 호환 확인.
- **S7 (성능·전송량)**: 신규 SVG 포함 첫 화면 ≤ 400KB 실측. CPU 4x에서 카드 사용 연출 끊김 없음.
- **S8 (접근성)**: 의도·상태가 아이콘화된 뒤에도 스크린리더용 텍스트(비주얼 히든)로 남아 있음.

## 5. 제약 조건

- CommonJS·무의존성·정적 파일. `engine.js`(1,645줄)·`content.js` 효과 정의 비접촉.
- 리플레이 로그 버전 유지 — 재현 의미가 바뀌는 변경이 불가피해지면 **중단하고 재승인** (매치3 특수 타일 선례: 버전 상향 필수 조건).
- 애니메이션 transform/opacity 한정, 상시 루프 금지, reduced-motion 존중.
- 신규 SVG는 가이드 라인 캐릭터 규칙 + 파일명 규칙(`deck-intent-*`, `deck-node-*`).
- CLAUDE.md 금기 위반 없음.
