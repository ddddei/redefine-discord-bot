## 0. 현재 상태

8×8·간식 7종·30수 점수제, 클릭+스와이프, 콤보 배율, v3 회화 타일, 주간/일일 랭킹·응원 연동 완료. 게임 규칙 자체는 출시 시점 그대로(가장 단순한 게임).

## 1. 백로그 (우선순위순)

### M1 — 특수 타일 (4·5매치 부스터) [효과 큼 / 중]

- 4매치 → 줄 제거 타일, 5매치/T·L자 → 주변 폭발 또는 동종 제거 타일. 매치3 장르의 핵심 재미 축인데 현재 없음.
- **주의**: `board.js` 캐스케이드·RNG 소비 순서가 바뀌면 시드 결정성이 깨짐 — 특수 타일 생성·발동을 결정적 규칙으로 설계(계획서에서 RNG 호출 순서 명세 필수). 점수 상한(`maxScore` 50,000) 재산정 동반.
- 오늘의 도전 재미를 가장 직접적으로 올리는 항목.

### M2 — 오늘의 도전 변형 규칙 [중 / 소]

- 요일별 변형: 수 제한 20수의 짧은 판, 특정 간식 수집 목표 등. dayKey 기반 결정적 규칙 선택(서버 `/daily` 응답에 변형 id 포함).
- M1 이후에 하면 조합 폭이 커짐.

### M3 — 목표 기반 모드 [중 / 중]

- "딸기 20개 지우기" 같은 판별 목표 + 성공/실패. 점수 무한 경쟁이 부담스러운 참여자에게 "완료" 만족을 주는 축(참여자 배려 원칙과 부합).
- 랭킹 밖 콘텐츠로 시작(제출 없음) — 부담 없는 병행 트랙.

### M4 — 연출 폴리시 [하 / 소]

- 드래그 중 타일 따라오기(모바일 하드닝 12절 이월), 큰 콤보 시 보드 반응 강화. 저사양 예산 내에서.
