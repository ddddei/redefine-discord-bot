# 프로젝트 리디파인 디스코드 안내 봇

프로젝트 리디파인 참여자들이 디스코드 안에서 프로그램 일정, 규칙, FAQ, 활동 안내를 확인할 수 있도록 만든 안내 봇입니다.

## 주요 기능

- `/안내`  
  처음 온 참여자를 위한 디스코드 사용 안내를 보여줍니다.

- `/질문`  
  리디파인 FAQ에서 관련 답변을 찾아 안내합니다.

- `/리디 도움`  
  사용할 수 있는 명령어를 안내합니다.

- `/리디 일정`  
  프로그램 일정 확인 방법을 안내합니다.

- `/리디 규칙`  
  참여 규칙을 안내합니다.

- `/리디 문의`  
  문의 방법을 안내합니다.

- `/공지`  
  운영진이 복사해 사용할 수 있는 공지 템플릿을 보여줍니다.  
  공지 템플릿은 실행한 사람에게만 보이도록 설정되어 있습니다.

## 기술 스택

- Node.js
- discord.js
- dotenv
- Discord Slash Command
